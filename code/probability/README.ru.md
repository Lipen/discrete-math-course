# probability

Дискретные распределения и ковариация.

Четыре распределения вырастают из одного испытания с вероятностью успеха $p$: Бернулли, биномиальное, геометрическое и Пуассона.
Модуль статистики считает среднее, дисперсию, ковариацию и коэффициент корреляции Пирсона для конечных наборов данных.

## Быстрый старт

```bash
cargo run --example distributions
cargo test
```

## Модель

### Распределения

| Распределение        | Значения       | $P(X = k)$                     | Среднее   | Дисперсия   |
| -------------------- | -------------- | ------------------------------ | --------- | ----------- |
| Бернулли$(p)$        | $0, 1$         | $p$ при $1$, $1-p$ при $0$     | $p$       | $p(1-p)$    |
| Биномиальное$(n, p)$ | $0, \ldots, n$ | $\binom{n}{k} p^k (1-p)^{n-k}$ | $np$      | $np(1-p)$   |
| Геометрическое$(p)$  | $1, 2, \ldots$ | $(1-p)^{k-1} p$                | $1/p$     | $(1-p)/p^2$ |
| Пуассона$(\lambda)$  | $0, 1, \ldots$ | $e^{-\lambda} \lambda^k / k!$  | $\lambda$ | $\lambda$   |

Распределение Пуассона — предел биномиального при $n \to \infty$, $p \to 0$ и $np \to \lambda$.
Тест `binomial_tends_to_poisson_for_rare_events` сравнивает массы при $n = 1000$, $p = 0.003$, $\lambda = 3$.

### Ковариация

Для наборов $x$ и $y$ одинаковой длины

$$
\operatorname{Cov}(X, Y) = \frac{1}{n} \sum_{i=1}^{n} (x_i - \bar{x})(y_i - \bar{y}),
\qquad
\rho(X, Y) = \frac{\operatorname{Cov}(X, Y)}{\sigma_X \sigma_Y}.
$$

Функции используют генеральную нормировку $1/n$, а не выборочную $1/(n-1)$.
Корреляция возвращает `None`, если дисперсия одного из наборов равна нулю.

Из независимости следует нулевая ковариация, но обратное неверно.
Тест `zero_covariance_without_independence` берёт $X$, равномерное на $\{-1, 0, 1\}$, и $Y = X^2$: величины зависимы, а ковариация равна нулю.

## API

| Элемент                    | Результат                                                              |
| -------------------------- | ---------------------------------------------------------------------- |
| `Distribution`             | `Bernoulli`, `Binomial`, `Geometric`, `Poisson`                        |
| `Distribution::pmf(k)`     | $P(X = k)$                                                             |
| `Distribution::mean()`     | $E[X]$                                                                 |
| `Distribution::variance()` | $\operatorname{Var}[X]$                                                |
| `mean(xs)`                 | среднее арифметическое, `None` для пустого среза                       |
| `variance(xs)`             | генеральная дисперсия, `None` для пустого среза                        |
| `covariance(xs, ys)`       | генеральная ковариация, `None` при несовпадении длин или пустых срезах |
| `correlation(xs, ys)`      | коэффициент Пирсона, `None` при нулевой дисперсии или плохом вводе     |

## Демо

| Демо            | Что показывает                                                                    |
| --------------- | --------------------------------------------------------------------------------- |
| `distributions` | массы и моменты четырёх распределений, хвост Пуассона и пример нулевой ковариации |

## Тесты

- масса и моменты Бернулли
- сумма масс биномиального равна единице, среднее и дисперсия
- время ожидания геометрического распределения
- сумма масс Пуассона равна единице, среднее равно дисперсии
- биномиальное приближается к Пуассону при редких событиях
- среднее и дисперсия конечного набора
- нулевая ковариация без независимости
- идеальная линейная корреляция
- отклонение несовпадающих и пустых входов
