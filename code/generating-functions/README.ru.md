# generating-functions

Усечённые формальные степенные ряды и последовательности, которые они кодируют.

Формальный степенной ряд — это бесконечный многочлен, который читают как последовательность коэффициентов.
`Series` хранит коэффициенты от степени $0$ до выбранной степени $N$, а остальные отбрасывает.
Сложение, умножение, умножение на скаляр, дифференцирование, интегрирование и обращение остаются внутри этого усечения, чего достаточно, чтобы восстановить первые $N + 1$ членов любой алгебраической производящей функции.

## Быстрый старт

```bash
cargo run --example catalan
cargo run --example fibonacci
cargo run --example partitions
cargo test
```

## Модель

Ряд записывают как

$$A(x) = a_0 + a_1 x + a_2 x^2 + \cdots$$

с коэффициентами из целых чисел.
Переменная $x$ — маркер позиции, а не число, поэтому вопрос о сходимости не возникает.
Усечение на $N$ оставляет $a_0, \dots, a_N$ и считает все более высокие коэффициенты нулевыми.
Это согласовано: коэффициент при $x^n$ в сумме, произведении или частном зависит только от коэффициентов степени не выше $n$ во входных рядах.

Произведение свёртывает коэффициенты.

$$(A B)_n = \sum_{k=0}^{n} a_k b_{n-k}$$

Деление — это умножение на обратный ряд.
Для ряда с постоянным членом $a_0 = \pm 1$ обратный ряд $g = 1/f$ определяется равенством $f g = 1$:

$$g_0 = \frac{1}{a_0}, \qquad g_n = -g_0 \sum_{k=1}^{n} a_k g_{n-k}$$

Постоянный член должен быть обратимым в целых числах, поэтому `inverse` возвращает `None` для любого другого постоянного члена.

Производная и интеграл действуют почленно.
Производная переводит $a_k$ в $k a_k$ и сдвигает на степень вниз.
Интеграл сдвигает на степень вверх и делит на новый показатель, используя целочисленное деление.
Оба сохраняют степень усечения входа.

## API

| Элемент                      | Результат                                                            |
| ---------------------------- | -------------------------------------------------------------------- |
| `Series::zeros(n)`           | нулевой ряд до степени `n`                                           |
| `Series::constant(c, n)`     | константа `c`, представленная до степени `n`                         |
| `Series::x(n)`               | ряд `x`, усечённый на степени `n`                                    |
| `Series::from_coeffs(&[..])` | ряд с заданными коэффициентами, степень на единицу меньше длины      |
| `coeff(k)`                   | коэффициент при `x^k`, или `0` выше степени усечения                 |
| `coefficients()`             | все сохранённые коэффициенты в виде среза                            |
| `degree()`                   | степень усечения `N`                                                 |
| `with_degree(n)`             | копия, усечённая или дополненная нулями до степени `n`               |
| `add(&other)`, `sub(&other)` | сумма и разность, усечённые на большей степени входов                |
| `mul(&other)`                | свёртка, усечённая на большей степени входов                         |
| `scale(c)`                   | каждый коэффициент, умноженный на `c`                                |
| `derivative()`, `integral()` | почленные производная и интеграл с той же степенью усечения          |
| `inverse()`                  | обратный ряд, `None` если постоянный член не `1` и не `-1`           |
| `catalan_numbers(n)`         | $C_0$ до $C_n$, неподвижная точка $C = 1 + x C^2$                    |
| `catalan_series(n)`          | производящая функция Каталана, усечённая на степени `n`              |
| `fibonacci_numbers(n)`       | коэффициенты $1/(1 - x - x^2)$, где $F_0 = F_1 = 1$                  |
| `fibonacci_series(n)`        | производящая функция Фибоначчи, усечённая на степени `n`             |
| `partition_numbers(n)`       | $p(0)$ до $p(n)$                                                     |
| `partition_series(n)`        | произведение $\prod_{k=1}^{n} 1/(1 - x^k)$, усечённое на степени `n` |

## Демо

| Демо         | Показывает                                                                   |
| ------------ | ---------------------------------------------------------------------------- |
| `catalan`    | итерацию $C \mapsto 1 + x C^2$, первые шесть итераций и $C_0$ до $C_{20}$    |
| `fibonacci`  | знаменатель $1 - x - x^2$, обратный ряд, $F_0$ до $F_{20}$ и золотое сечение |
| `partitions` | множители произведения, частичные произведения и $p(0)$ до $p(20)$           |

## Сложность

При степени усечения $N$:

| Операция                 | Время    | Память |
| ------------------------ | -------- | ------ |
| `add`, `sub`, `scale`    | $O(N)$   | $O(N)$ |
| `derivative`, `integral` | $O(N)$   | $O(N)$ |
| `mul`                    | $O(N^2)$ | $O(N)$ |
| `inverse`                | $O(N^2)$ | $O(N)$ |
| `fibonacci_series(N)`    | $O(N^2)$ | $O(N)$ |
| `catalan_series(N)`      | $O(N^3)$ | $O(N)$ |
| `partition_series(N)`    | $O(N^3)$ | $O(N)$ |

Итерация Каталана требует $N$ применений отображения $C \mapsto 1 + x C^2$, каждое стоит $O(N^2)$.
Произведение для разбиений требует $N$ обращений и $N$ умножений, каждое стоит $O(N^2)$.
Коэффициенты — `i64`, поэтому значения выше примерно $9 \cdot 10^{18}$ переполняются.

## Тесты

`cargo test` запускает модульные тесты в `src/` и проверки префиксов в `tests/`.
Модульные тесты покрывают свёртку и усечение, рекуррентность обратного ряда при обоих знаках постоянного члена, отказ для остальных постоянных членов и круговой обход производной и интеграла.
Проверки префиксов сравнивают три последовательности с таблицами и с рекуррентностью Фибоначчи.
