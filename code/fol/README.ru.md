# fol

Логика первого порядка: термы, формулы, модели и истинность в стиле Тарского.

## Быстрый старт

```bash
cargo run --example mortal
cargo run --example quantifier_scope
cargo run --example substitution
cargo run --example validity
cargo test
```

## Идея

Язык первого порядка задаётся сигнатурой: константы, функциональные и предикатные символы, два последних — с арностями.
Термы — переменные, константы и применения функций.
Формулы строятся грамматикой

$$\varphi \;::=\; P(t_1, \dots, t_n) \;\mid\; t_1 = t_2 \;\mid\; \neg\varphi \;\mid\; \varphi \land \varphi \;\mid\; \varphi \lor \varphi \;\mid\; \varphi \to \varphi \;\mid\; \forall x.\,\varphi \;\mid\; \exists x.\,\varphi$$

### Модели и истинность

Структура придаёт символам значение: непустой домен $D$, значение для каждой константы, тотальная функция для каждого функционального символа, отношение для каждого предиката.
Истинность предложения вычисляется по индуктивному определению Тарского, которое реализует `Structure::eval`.
Сердце определения — случай кванторов:

$$\mathcal{M} \models \forall x.\,\varphi \iff \mathcal{M} \models \varphi[x := d] \text{ для каждого } d \in D$$

$$\mathcal{M} \models \exists x.\,\varphi \iff \mathcal{M} \models \varphi[x := d] \text{ для некоторого } d \in D$$

Порядок кванторов важен: `∀x ∃y L(x, y)` позволяет `y` зависеть от `x`, а `∃y ∀x L(x, y)` фиксирует один `y` для всех.
Предикаты и кванторы позволяют формуле заглянуть внутрь атома: `P(x)` — шаблон, который становится высказыванием, когда `x` связан квантором или заменён константой.

### Разрешимость на конечных доменах

На конечном домене кванторы сводятся к конечным связкам:

$$\forall x.\,\varphi \;\equiv\; \bigwedge_{d \in D} \varphi[x := d] \qquad\qquad \exists x.\,\varphi \;\equiv\; \bigvee_{d \in D} \varphi[x := d]$$

Структур над фиксированным конечным доменом конечное число, поэтому выполнимость и общезначимость разрешимы перебором.
`enumerate_structures` перечисляет их все, а `satisfiable_over` и `valid_over` отвечают на два вопроса.

### Подстановка

`Formula::substitute` заменяет свободную переменную термом.
Подстановка обходится без захвата: связанная переменная сначала переименовывается, если входящий терм иначе был бы захвачен.

## Демо

| Демо               | Что показывает                                                                                          |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| `mortal`           | «Каждый человек смертен» истинно в одном мире и ложно в другом                                          |
| `quantifier_scope` | `∀x ∃y L(x, y)` против `∃y ∀x L(x, y)` — порядок меняет истинность                                      |
| `substitution`     | Подстановка без захвата: связывающая переменная переименовывается, входящий терм остаётся свободным     |
| `validity`         | Закон исключённого третьего общезначим над конечными доменами, а `∃x P(x)` выполнима, но не общезначима |

## API

| Элемент                                                                | Что делает                                                                        |
| ---------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `Signature`                                                            | Константы, функции и предикаты языка с арностями                                  |
| `Term`                                                                 | Терм: `Var`, `Const`, `Fun`                                                       |
| `Formula`                                                              | Формула: `Pred`, `Eq`, `Not`, `And`, `Or`, `Implies`, `Forall`, `Exists`          |
| `var` / `constant` / `func`                                            | Конструкторы термов                                                               |
| `pred` / `eq` / `not` / `and` / `or` / `implies` / `forall` / `exists` | Конструкторы формул                                                               |
| `Term::substitute`                                                     | Заменяет переменную термом                                                        |
| `Formula::substitute`                                                  | Подстановка без захвата, при необходимости переименовывает связанные переменные   |
| `Formula::free_vars`                                                   | Свободные переменные формулы                                                      |
| `Structure`                                                            | Модель: домен и интерпретация каждого символа                                     |
| `Structure::eval`                                                      | Истинность предложения по Тарскому, `eval_with` добавляет присваивание переменных |
| `enumerate_structures`                                                 | Все структуры над фиксированным конечным доменом                                  |
| `satisfiable_over` / `valid_over`                                      | Выполнимость / общезначимость над фиксированным конечным доменом                  |
| `domain`                                                               | Канонический домен из `n` индивидов с именами `"0"` .. `"n-1"`                    |

## Тесты

Интеграционные тесты сверяют вычисление истинности с ручными расчётами: порядок кванторов, форма силлогизма о смертности, равенство как совпадение элементов домена и подстановка без захвата.
Тесты перечисления решают выполнимость и общезначимость на малых доменах, включая подсчёт структур над доменами размера 1 и 2.
