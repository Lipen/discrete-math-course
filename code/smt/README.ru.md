# smt

Небольшой стек DPLL(T) для бескванторных задач SMT.

SAT-решатель разбирается с булевой структурой, решатели теорий — с конъюнкциями арифметических или битовых литералов, а драйвер объединяет то и другое.
Каждый атом теории абстрагируется до булевой переменной, и каждый конфликт теории даёт новый выученный дизъюнкт.

## Быстрый старт

```bash
cargo run --example solve      # разностная логика, выполнимо
cargo run --example unsat      # разностная логика, отрицательный цикл
cargo run --example mixed      # смешанная формула через драйвер DPLL(T)
cargo test
```

## Слои

| Модуль       | Что делает                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------------- |
| `sat`        | Автономный SAT-решатель DPLL: единичное распространение, решения, возврат, движок для всех остальных модулей                |
| `difference` | Разностная логика `x - y <= c`: проверка на отрицательный цикл методом Беллмана–Форда                                       |
| `linear`     | Линейная арифметика над вещественными числами методом исключения Фурье–Моцкина с точной рациональной арифметикой (`Rat`)    |
| `integers`   | Линейная целочисленная арифметика методом ветвей и границ на рациональной релаксации                                        |
| `bitvec`     | Битовые векторы фиксированной ширины методом bit-blasting: каждое выражение превращается в схему из дизъюнктов для SAT-ядра |
| `driver`     | Цикл DPLL(T): `smt::check(formula)` для смешанных формул с наивным изучением конфликтов                                     |

### Осознанные ограничения

Драйвер намеренно прост: одна теория на атом, без комбинации Нельсона–Оппена с обменом переменными между теориями.

- Линейные атомы-равенства отклоняются, потому что их отрицание — дизъюнкция: записывайте `sum == b` как два атома `sum <= b` и `-sum <= -b`.
- `linear` и `integers` ведут всю арифметику точно, но ожидают небольших коэффициентов: исключение их перемножает.
- `bitvec` принимает ширины от 1 до 64 бит и операции `Not`, `And`, `Or`, `Add`, `Sub`, `Extract`, `Eq`, `Neq`.
- `Mul` и `Shl` завершаются явной ошибкой, а не неверным ответом.

## Демо

| Демо    | Что показывает                                                                                                                                                     |
| ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `solve` | Выполнимая система разностной логики (`4 <= x0 - x1 <= 5` и `x2 - x1 <= 2`), найденное присваивание и повторная проверка каждого ограничения                       |
| `unsat` | Противоречивая пара (`x0 - x1 <= 2` и `x1 - x0 <= -3`), образующая отрицательный цикл: решатель возвращает `None`                                                  |
| `mixed` | Выполнимая смесь разностной логики, линейной арифметики и 4-битного `secret + 1 == 5`, а также невыполнимая дизъюнкция, ветви которой отвергаются разными теориями |

Смешанная формула — это булева комбинация атомов теорий:

$$\varphi \;::=\; A \;\mid\; \neg\varphi \;\mid\; \varphi \land \varphi \;\mid\; \varphi \lor \varphi$$

где $A$ пробегает атомы `Atom::Diff`, `Atom::Linear`, `Atom::Integer` и `Atom::Bitvec`:

```rust
use smt::difference::Constraint as Diff;
use smt::driver::{Atom, Formula, Verdict};

// (x0 - x1 <= 2) OR (x1 - x0 <= -3): задача, которая занимает не более 2
// единиц времени или не менее 3.
let f = Formula::Or(
    Box::new(Formula::Atom(Atom::Diff(Diff { x: 0, y: 1, c: 2 }))),
    Box::new(Formula::Atom(Atom::Diff(Diff { x: 1, y: 0, c: -3 }))),
);
assert_eq!(smt::check(&f).unwrap(), Verdict::Sat);
```

Драйвер абстрагирует атомы до булевых переменных, передаёт каждую модель SAT-ядра решателю разностной логики, а при отказе выучивает отрицание нарушенного набора литералов как новый дизъюнкт.

## API

| Элемент                                 | Что делает                                                                              |
| --------------------------------------- | --------------------------------------------------------------------------------------- |
| `sat::solve(num_vars, &clauses)`        | Булева модель (одно значение на переменную) или `None`                                  |
| `sat::Solver`                           | Инкрементальные дизъюнкты, `solve()` можно повторять после изучения                     |
| `difference::Constraint { x, y, c }`    | Литерал `x - y <= c`                                                                    |
| `difference::solve(&[Constraint])`      | Присваивание или `None` (отрицательный цикл)                                            |
| `linear::Constraint { coeffs, b, rel }` | `sum <rel> b` над вещественными числами (`Le`, `Lt`, `Eq`)                              |
| `linear::solve(&[Constraint])`          | Точное рациональное присваивание или `None`                                             |
| `linear::Rat`                           | Точное рациональное число `num / den` с `to_f64`, `floor`, `ceil`                       |
| `integers::Constraint { coeffs, b }`    | `sum <= b` над целыми числами                                                           |
| `integers::solve(&[Constraint])`        | Целочисленное присваивание или `None`                                                   |
| `bitvec::Expr`                          | Выражения битовых векторов: `Const`, `Var`, `Not`, `And`, `Or`, `Add`, `Sub`, `Extract` |
| `bitvec::BoolExpr`                      | Верхнеуровневые литералы `Eq` / `Neq`                                                   |
| `bitvec::solve(&[BoolExpr])`            | `Ok(Some(model))` / `Ok(None)` / `Err(BitvecError)`                                     |
| `driver::Atom`                          | Атом `Diff`, `Linear`, `Integer` или `Bitvec`                                           |
| `driver::Formula`                       | `Atom`, `Not`, `And`, `Or`                                                              |
| `smt::check(&Formula)`                  | `Ok(Sat)` или `Ok(Unsat)`, либо ошибка для неподдерживаемых литералов                   |

## Тесты

SAT-ядро сравнивается с полным перебором таблицы истинности по фиксированному набору дизъюнктов.
Решатели теорий проверяются на выполнимых и невыполнимых системах.
Тесты битовых векторов заново проверяют каждую найденную модель по исходным выражениям.
