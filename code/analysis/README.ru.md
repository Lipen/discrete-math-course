# analysis

Абстрактная интерпретация: домен констант, переносящие функции и итерация до неподвижной точки.

Крошечная императивная программа анализируется на абстрактных значениях.
Домен констант отслеживает, какие переменные содержат известное целое: ⊥ — недостижимо, ⊤ — «не константа».

## Быстрый старт

```bash
cargo run --example constant_propagation
cargo run --example distributive_flow
cargo test
```

## Модель

### Решётка констант

Порядок по информации ставит ⊥ ниже любой известной константы ниже ⊤, а две разные константы несравнимы:

$$\bot \;\sqsubset\; n \;\sqsubset\; \top \quad (n \in \mathbb{Z}) \qquad m \,\parallel\, n \quad (m \neq n)$$

Объединение сливает состояния ветвей: равные значения остаются, разные константы проваливаются в ⊤, ⊥ нейтрально.

| $x \sqcup y$ | ⊥            | $n$                        | ⊤   |
| ------------ | ------------ | -------------------------- | --- |
| ⊥            | ⊥            | $n$                        | ⊤   |
| $m$          | $m$          | $m$, если $m = n$, иначе ⊤ | ⊤   |
| ⊤            | ⊤            | ⊤                          | ⊤   |

### Переносящие функции

Присваивания вычисляют выражения абстрактно:

- абстрактный `+` известен, только когда известны оба операнда, а любой операнд ⊥ делает результат ⊥
- абстрактный `*` перемножает известные константы и убивает неопределённость нулём: $0 \cdot \top = 0$
- абстрактное отрицание меняет знак известной константы и оставляет ⊥ и ⊤ без изменений

`if` запускает обе ветви на копиях состояния и сливает результаты через ⊔.

### Итерация Клини

Цикл `while` анализируется от состояния на входе в цикл $E$: каждый проход вычисляет тело на текущем состоянии, объединяет результат с $E$ и останавливается, когда состояние перестаёт меняться:

$$d_{k+1} \;=\; E \;\sqcup\; F_B(d_k)$$

Так как объединение двух разных констант даёт ⊤ (и каждая операция сохраняет ⊤), возрастающая цепочка коротка, и итерация сходится за несколько проходов.

## Демо

| Демо                    | Что показывает                                                                                                                |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `constant_propagation`  | Константы через арифметику, потеря точности из-за ветвлений и $0 \cdot \top = 0$                                              |
| `distributive_flow`     | Зачем нужна дистрибутивность функций потока: $f(x \sqcup y)$ против $f(x) \sqcup f(y)$ на монотонной и дистрибутивной функции |

`distributive_flow` противопоставляет монотонную функцию потока, которая может приобрести факты от слитного входа ($f(x \sqcup y) \supsetneq f(x) \sqcup f(y)$), и дистрибутивную, у которой оба порядка совпадают, — свойство, на которое опирается класс анализов IFDS.

## API

| Элемент                    | Назначение                                                                                |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| `Const`                    | Домен констант (⊥, известные значения, ⊤) с `+`, `*`, `-` и `lub` (⊔)                     |
| `Expr`, `Stmt`             | Крошечная императивная программа                                                          |
| `State<D>`                 | Абстрактное состояние: значение на переменную                                             |
| `eval_const`               | Абстрактное вычисление выражения в домене констант                                        |
| `exec_const`               | Выполнить операторы: присваивания переносят, ветви сливаются, циклы доходят до фикс-точки |
| `assign`, `inc`            | Построители для `x := n` и `x := x + 1`                                                   |

## Тесты

- законы решётки домена констант и его абстрактная арифметика
- слияние ветвей и теряемая при нём точность
- сходимость итерации Клини на цикле `while`
- правило «ноль убивает неопределённость» на результате ветвления
