# type-theory

Просто типизированное λ-исчисление (λ→).

Термы с аннотациями Чёрча проверяются по правилам var/app/abs, бестиповые термы получают наиболее общий тип унификацией, а β-редукция типизированного терма сохраняет его тип.

## Быстрый старт

```bash
cargo test
cargo run --example typed_terms
cargo run --example inference
cargo run --example subject_reduction
```

## Система типов

Типы строятся из имён базовых типов и стрелок, стрелки правоассоциативны: `Nat -> Nat -> Nat` читается как `Nat -> (Nat -> Nat)`.

$$\sigma ::= B \mid \sigma \to \tau$$

Три правила типизации — вся система:

$$
   \frac{}{(x:\sigma)\in\Gamma}\;\textbf{var} \\[1em]
   \frac{\Gamma\vdash M:\sigma\to\tau\quad\Gamma\vdash N:\sigma}{\Gamma\vdash MN:\tau}\;\textbf{app} \\[1em]
   \frac{\Gamma,x:\sigma\vdash M:\tau}{\Gamma\vdash\lambda x:\sigma.\;M:\sigma\to\tau}\;\textbf{abs}
$$

### Проверка типов

Проверка терма с аннотациями (`λx:σ. M`) — обход по этим правилам: переменная ищет свой тип в контексте, связыватель расширяет контекст, а применение сравнивает тип аргумента с областью определения функции.
Тождество `λx:A. x` типизируется как `A -> A` одним шагом `var` под одним шагом `abs`:

$$
\frac{
   \frac{}{(x:A)\in\Gamma}\;\textbf{var}
}{
   \vdash \lambda x:A.\;x : A \to A
}\;\textbf{abs}
$$

### Вывод типов

Вывод типа бестипового терма назначает каждому связывателю свежую метапеременную и унифицирует ограничения трёх правил (алгоритм W).
Несвязанные метапеременные `?0`, `?1`, ... обобщаются в порядке первого появления в схематические переменные `a`, `b`, ..., поэтому тождество выводится как схема `a -> a`.
Поскольку `x` в `λx. x x` должен был бы быть одновременно аргументом и функцией, вывод требует `σ = σ -> τ`, что отвергается проверкой вхождения (occurs check).

## Канонические термы

| Терм          | Проверка      | Вывод         | Чтение                                          |
| ------------- | ------------- | ------------- | ----------------------------------------------- |
| `λx. x`       | `σ -> σ`      | `a -> a`      | тождественная функция                           |
| `λx. λy. x`   | `σ -> τ -> σ` | `a -> b -> a` | аксиома `A -> B -> A` минимальной логики        |
| `ω = λx. x x` | отвергается   | отвергается   | нужен `σ = σ -> τ`                              |
| `Ω = ω ω`     | отвергается   | отвергается   | содержит `ω`, терм не завершается               |

При проверке на `Nat` тождество читается как `Nat -> Nat`.

## Сохранение типа при редукции

Тип — *инвариант* вычисления: если `Γ ⊢ M : σ` и `M →β M'`, то `Γ ⊢ M' : σ`.
Редукция `STerm` сохраняет аннотации связывателей, поэтому за каждым β-шагом типизированного терма может следовать повторная проверка.

## Модули

| Модуль    | Содержимое                                                                                                    |
| --------- | ------------------------------------------------------------------------------------------------------------- |
| `ty`      | `Type` (`Base`, `Arrow`, `Var`), `Context` с предположениями о типах переменных, отображение                  |
| `term`    | Бестиповый `Term` (`Var`, `Abs`, `App`), подстановка без захвата, β-редукция                                  |
| `checker` | `STerm` с аннотациями Чёрча, правила var/app/abs в `STerm::check`, стирание, `TypeError`, шаги редукции       |
| `infer`   | Вывод на основе унификации (алгоритм W): метапеременные, проверка вхождения, схематические типы, `InferError` |

## Демо

| Демо                 | Что показывает                                                                                                                                            |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `typed_terms`        | Проверка тождества, K, числа Чёрча и композиции, с отвержением некорректно типизированных термов (самоприменение, несоответствие, несвязанная переменная) |
| `inference`          | Вывод наиболее общего типа тождества, K, S и Чёрча 2, с отвержением $\omega$ и $\Omega$ проверкой вхождения                                               |
| `subject_reduction`  | `(λf:A→A. λx:A. f x)(λx:A. x)` редуцируется к `λx:A. x`, тип `A → A` сохраняется на каждом шаге                                                           |

## API

| Элемент                                      | Назначение                                                          |
| -------------------------------------------- | ------------------------------------------------------------------- |
| `Type::base` / `Type::nat` / `Type::boolean` | Базовые типы                                                        |
| `Type::arrow`                                | Функциональный тип `dom -> cod`                                     |
| `Type::var`                                  | Типовая переменная (схематическая `a` или метапеременная `?0`)      |
| `Context::new` / `extend` / `lookup`         | Контекст типизации: побеждает самая внутренняя привязка             |
| `Term::var` / `abs` / `app`                  | Конструкторы бестиповых термов                                      |
| `Term::beta_reduce` / `normalize`            | Один β-шаг / нормальная форма (с ограничением топлива)              |
| `Term::substitute`                           | Подстановка без захвата $M[x := N]$                                 |
| `STerm::var` / `abs` / `app`                 | Конструкторы термов с аннотациями Чёрча                             |
| `STerm::check` / `type_of`                   | Проверка типа по контексту / по пустому контексту                   |
| `STerm::erase`                               | Стирание аннотаций до бестипового `Term`                            |
| `STerm::beta_reduce` / `normalize`           | β-редукция с сохранением аннотаций (сохранение типа)                |
| `infer` / `infer_in`                         | Наиболее общий тип бестипового терма                                |
| `TypeError` / `InferError`                   | Почему терм не прошёл проверку типа                                 |

## Тесты

Модульные и документационные тесты покрывают:

- типизацию тождества и K
- отвержение самоприменения $\omega = \lambda x.\;x\;x$
- сохранение типа при редукции на примере детура
