# algebra

Алгебраические структуры как типажи Rust: полугруппа, моноид, группа, кольцо, поле — плюс гомоморфизмы групп, факторгруппы и конечные поля `GF(2^m)`.

У каждой структуры — типаж и конкретные экземпляры:

- классы вычетов `Zn<N>` и их единицы `Unit<N>`
- перестановки `Perm<N>`, симметрическая группа `S_N`
- двухэлементное поле `Bool`, `GF(2)`
- диэдральная группа `D4`, симметрии квадрата
- полиномиальные поля `Gf4` и `Gf256`: `GF(4)` и байтовое поле AES
- натуральные числа Пеано `Nat` и алгоритм Евклида — конкретные определения ещё до появления встроенных числовых типов

## Быстрый старт

```bash
cargo test
cargo run --example from_scratch
cargo run --example groups
cargo run --example rings
cargo run --example cayley
cargo run --example dihedral
cargo run --example table_group
cargo run --example homomorphism
cargo run --example finite_field
```

## Идея

### Иерархия типажей

Каждый типаж добавляет один ингредиент к предыдущему:

| Типаж       | Добавляет                                                          | Закон                                      |
| ----------- | ------------------------------------------------------------------ | ------------------------------------------ |
| `Semigroup` | ассоциативную операцию `op`                                        | `(a op b) op c = a op (b op c)`            |
| `Monoid`    | нейтральный элемент                                                | `identity().op(a) = a.op(&identity()) = a` |
| `Group`     | обратный элемент                                                   | `a.op(&a.inverse()) = identity()`          |
| `Ring`      | `add` и `mul` с `zero`, `one`, `neg`, связанными дистрибутивностью | `a * (b + c) = a*b + a*c`                  |
| `Field`     | обратный к каждому ненулевому элементу                             | `a * a^{-1} = 1` при `a != 0`              |

### Конструкции

Вокруг типажей выстроены стандартные конструкции:

- степени и порядки одного элемента и порождаемая им циклическая подгруппа
- таблицы Кэли с проверками аксиом
- гомоморфизмы с ядрами, образами и смежными классами
- операция факторгруппы из первой теоремы об изоморфизме

### Конечные поля

Конечные поля строят `GF(2^m)` как фактор кольца многочленов над `GF(2)`:

$$GF(2^m) \cong GF(2)[x]/(f(x))$$

для неприводимого многочлена $f$ степени $m$: сложение — это XOR битов коэффициентов, а умножение — умножение многочленов по модулю $f$.

Скобки в $(f(x))$ обозначают идеал, порождённый $f$: множество всех кратных $f$, так что в один класс попадают ровно те многочлены, которые отличаются на такое кратное.

### Слой типов

Сами типы образуют полукольцо, и крейт ведёт его на уровне типов:

$$|A + B| = |A| + |B| \qquad |A \times B| = |A| \cdot |B| \qquad |B^A| = |B|^{|A|}$$

Законы выполняются с точностью до изоморфизма, удостоверенного парами взаимно обратных функций.

## Демо

| Демо           | Что показывает                                                                       |
| -------------- | ------------------------------------------------------------------------------------ |
| `from_scratch` | Сложение и умножение Пеано, gcd и модулярный обратный из коэффициентов Безу          |
| `groups`       | Вычеты по модулю 8, перестановки, группа единиц `Z_8^*`: порядки, степени, подгруппы |
| `rings`        | Делители нуля в `Z_6`, единицы `Z_5`, поле `GF(2)`                                   |
| `cayley`       | Таблица Кэли для `Z_4` и свойство латинского квадрата                                |
| `dihedral`     | `D_4`: порядки, таблица Кэли, некоммутативность, подгруппа поворотов                 |
| `table_group`  | Группа как чистые данные: проверки аксиом и контрпример не-группы                    |
| `homomorphism` | Отображение `Z_6 -> Z_3`, его ядро и смежные классы, первая теорема об изоморфизме   |
| `finite_field` | Таблицы сложения и умножения `GF(4)`, примитивный элемент, порядки в `GF(256)`       |

`from_scratch` считает на одних данных: значениях `Nat`, построенных из `Zero` и `Succ`, затем `gcd` и `extended_gcd` на обычных целых числах.
`homomorphism` показывает первую теорему об изоморфизме на `Z_6 -> Z_3`: ядро нормально, его смежные классы разбивают группу, и на каждый элемент образа приходится ровно один класс.
`finite_field` печатает таблицы `GF(4)`, выводит $\alpha^2 = \alpha + 1$ из $x^2 + x + 1 = 0$ и сравнивает порядки элементов в байтовом поле AES `GF(256)`.

## API

### Типажи

| Элемент                        | Что делает                                              |
| ------------------------------ | ------------------------------------------------------- |
| `Semigroup`, `Monoid`, `Group` | Иерархия с одной операцией: `op`, `identity`, `inverse` |
| `Ring`, `Field`                | Иерархия с двумя операциями: `add`, `mul`, `neg`, `inv` |

### Экземпляры

| Элемент                      | Что делает                                                             |
| ---------------------------- | ---------------------------------------------------------------------- |
| `Zn<N>`                      | Классы вычетов по модулю `N`: аддитивная группа и кольцо               |
| `Unit<N>`                    | Единицы `Z_N`: мультипликативная группа `Z_N^*`                        |
| `Perm<N>`                    | Перестановки `N` элементов: симметрическая группа `S_N`                |
| `Bool`                       | `GF(2)`: булевы значения с XOR и AND, наименьшее поле                  |
| `Nat`                        | Натуральные числа Пеано с единственными конструкторами `Zero` и `Succ` |
| `D4`                         | Диэдральная группа порядка 8: симметрии квадрата                       |
| `TableGroup`                 | Конечная группа, заданная только таблицей Кэли, с проверками аксиом    |
| `Gf<M, MOD>`, `Gf4`, `Gf256` | Конечные поля `GF(2^m)`: `GF(4)` и байтовое поле AES                   |

### Функции

| Элемент                                     | Что делает                                           |
| ------------------------------------------- | ---------------------------------------------------- |
| `gcd`, `extended_gcd`, `mod_inverse`        | Алгоритм Евклида и коэффициенты Безу                 |
| `power`, `order`, `subgroup`, `is_abelian`  | Общие вспомогательные функции для групп              |
| `is_homomorphism`, `kernel`, `image`        | Сохраняющие структуру отображения и их инварианты    |
| `left_cosets`, `is_normal`, `coset_product` | Смежные классы, нормальность и операция факторгруппы |

### Слой типов

| Элемент                                | Что делает                                                                   |
| -------------------------------------- | ---------------------------------------------------------------------------- |
| `Type`                                 | Типы как данные: полукольцо типов с `cardinality` и `simplify`               |
| `Zero`, `One`, `Sum`, `Prod`           | Полукольцо на уровне типов `0`, `1`, `+`, `*` с доказательствами изоморфизма |
| `BoolSet<T>`                           | Булеан как булево кольцо: симметрическая разность и пересечение              |
| `Category`, `Hask`, `compose`, `id`    | Категория множеств: функции как морфизмы                                     |
| `curry`, `uncurry`, `constant`, `flip` | Экспоненциалы и комбинаторы морфизмов                                        |
| `Functor`, `Fix`, `OptionF`, `cata`    | Функторы и неподвижные точки: `Nat = Fix(Option)`                            |

## Тесты

`tests/algebra_test.rs` исчерпывающе проверяет аксиомы на конечных экземплярах:

- ассоциативность в `Z_5`, `S_3`, `Z_6` и в единицах `Z_8`
- дистрибутивность в `Z_6`
- законы поля в `GF(2)`

Юнит-тесты в модулях проверяют порядки, обратные элементы, разбиение на смежные классы и изоморфизмы вместе с их обратными отображениями.
