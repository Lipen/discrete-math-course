# lambda

Бестиповое λ-исчисление: термы с подстановкой без захвата, три стратегии редукции с ограничением топлива, кодировки Чёрча, комбинаторы SKI и просто типизированный слой.

## Быстрый старт

```bash
cargo test
cargo run --example church_arith
cargo run --example combinators
cargo run --example beta_trace
```

## Идея

β-редукция подаёт аргумент в связыватель, заменяя каждое свободное вхождение связанной переменной:

$$ (\lambda x.\; M)\; N \;\to_\beta\; M[x := N] $$

Подстановка выполняется без захвата: когда свободная переменная $N$ могла бы быть захвачена связывателем, связыватель сначала α-переименовывается.

![Бета-редукция комбинатора K](assets/beta-reduction.svg)

На схеме шаг за шагом редуцируется комбинатор-константа $(\lambda x.\,\lambda y.\,x)\;a\;b$.

## Стратегии редукции

Все драйверы ограничены топливом (`max_steps`), поэтому расходящиеся термы вроде $\Omega$ не могут подвесить процесс, а результат возвращается как `Reduction` со счётчиком шагов.

- **Нормальный порядок** (самый левый внешний) — если нормальная форма существует, нормальный порядок её находит.
- **Аппликативный порядок** (самый левый внутренний) — аргументы редуцируются до применения функции, поэтому он может зациклиться там, где нормальный порядок завершается (когда аргумент расходится).
- **Слабая головная нормальная форма** — выполнение останавливается, как только головка становится переменной или связывателем, а редексы внутри аргументов не трогаются.

## Модули

| Модуль        | Содержимое                                                                 |
| ------------- | -------------------------------------------------------------------------- |
| `term`        | `Term` (`Var`, `Abs`, `App`), конструкторы, печать, свободные переменные   |
| `subst`       | Подстановка без захвата $M[x := N]$ и α-преобразование `rename`            |
| `eval`        | Стратегии редукции и драйверы с ограничением топлива и счётчиками шагов    |
| `church`      | Числа Чёрча, булевы значения, пары, проверка нуля, предшественник          |
| `combinators` | Комбинаторы I, K, S (S и K образуют базис)                                 |
| `stlc`        | Просто типизированный слой: `Ty`, `STerm`, проверка типов, стирание типов  |

## Демо

| Демо           | Что показывает                                                                  |
| -------------- | ------------------------------------------------------------------------------- |
| `church_arith` | Числа Чёрча: `succ`, `add`, `mult`, `power` ($2^4 = 16$)                        |
| `combinators`  | I, K, S и редукция `S K K` к тождеству                                          |
| `beta_trace`   | Пошаговые следы β-редукции, включая `succ` Чёрча, применённый к 2               |

## API

### Термы и редукция

| Элемент                                                      | Назначение                                                                          |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| `Term` (`Var`, `Abs`, `App`)                                 | λ-терм                                                                              |
| `Term::var` / `Term::abs` / `Term::app`                      | конструкторы                                                                        |
| `Term::free_vars`                                            | свободные переменные терма                                                          |
| `Term::substitute`                                           | подстановка без захвата $M[x := N]$                                                 |
| `Term::rename`                                               | α-преобразование (переименование связанной переменной)                              |
| `Term::beta_reduce`                                          | один β-шаг нормального порядка, `None` в нормальной форме                           |
| `Term::beta_reduce_applicative`                              | один β-шаг аппликативного порядка (самый левый внутренний)                          |
| `Term::whnf_step`                                            | один шаг к слабой головной нормальной форме                                         |
| `Term::normalize`                                            | редукция нормального порядка до нормальной формы, с ограничением топлива            |
| `Term::normalize_applicative`                                | редукция аппликативного порядка, с ограничением топлива                             |
| `Term::whnf`                                                 | редукция к слабой головной форме, с ограничением топлива                            |
| `Term::reduce_normal` / `reduce_applicative` / `reduce_whnf` | те же прогоны, возвращающие `Reduction` со счётчиком шагов                          |
| `Reduction`                                                  | `{ term, steps, converged }` — достигнутый терм, сделанные шаги, состояние топлива  |
| `Term::trace` / `trace_applicative`                          | пошаговые следы редукции                                                            |
| `Term::is_normal_form` / `is_whnf`                           | предикаты нормальной формы                                                          |

### Кодировки Чёрча

| Элемент                             | Назначение                                            |
| ----------------------------------- | ----------------------------------------------------- |
| `church` / `to_nat`                 | числа Чёрча и чтение их значения обратно              |
| `succ` / `add` / `mult` / `power`   | арифметика на числах Чёрча                            |
| `is_zero` / `pred`                  | проверка нуля и предшественник (сдвиг пары)           |
| `church_true` / `church_false`      | булевы значения Чёрча                                 |
| `and` / `or` / `not` / `ifthenelse` | булева логика                                         |
| `church_to_bool`                    | интерпретация булева значения Чёрча обратно в `bool`  |
| `pair` / `fst` / `snd`              | пары Чёрча и проекции                                 |

### Комбинаторы

| Элемент         | Назначение                                 |
| --------------- | ------------------------------------------ |
| `i` / `k` / `s` | комбинаторы SKI (S и K образуют базис)     |

### Просто типизированный слой

| Элемент                    | Назначение                                                                   |
| -------------------------- | ---------------------------------------------------------------------------- |
| `Ty` / `STerm`             | просто типизированные термы: `Base`, `Arrow`, аннотированные связыватели     |
| `STerm::erase`             | стирание типов до бестипового `Term`                                         |
| `STerm::infer` / `type_of` | проверка типа по контексту или по пустому контексту                          |
| `TypeError`                | почему типизированный терм не прошёл проверку                                |

## Тесты

Модульные тесты покрывают:

- граничные случаи подстановки без захвата: переименование под вложенными связывателями, границы затенения, имена, связанные глубже в теле
- расходимость аппликативного порядка на $\Omega$ там, где нормальный порядок завершается
- поведение слабой головной формы: редексы внутри аргументов не трогаются
- арифметические тождества кодировок Чёрча
