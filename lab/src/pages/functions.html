Что здесь показано

Инъекция

Разные элементы домена имеют разные образы. В диаграмме нет двух стрелок в одну вершину.

Сюръекция

У каждого элемента кодомена есть прообраз. Пропущенных вершин справа нет.

Биекция

Инъекция и сюръекция одновременно. У такой функции есть обратная: каждый элемент кодомена возвращается к своему прообразу.

Образ и прообраз

Образ множества состоит из значений на его элементах. Прообраз состоит из элементов домена, попавших в заданное множество.
