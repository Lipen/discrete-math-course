# Лаборатории

Интерактивный стенд курса: пятнадцать лабораторий и каталог.
Исходники на TypeScript, выход --- статические файлы для GitHub Pages.

## Быстрый старт

Нужен только Bun 1.4 или новее, `just` удобен, но не обязателен.

Три способа, от самого простого:

1. Открыть готовую сборку файлом.
   `just lab` собирает `lab/dist`, после чего `lab/dist/index.html` открывается двойным щелчком, без сервера.
2. Живая разработка.
   `just lab-dev` собирает, следит за `src/` и отдаёт страницы на `http://localhost:8765`.
   Порт меняется переменной окружения: `PORT=8790 just lab-dev`.
3. Весь сайт курса.
   `just site-serve` собирает лабы, хаб и превью PDF, затем отдаёт `site/dist` на том же порту.

Проверки и smoke требуют установки зависимостей один раз:

```sh
cd lab
bun install
bunx playwright install chromium   # только для smoke
```

## Команды

| Команда | Что делает |
|---|---|
| `bun run build` | собирает `dist`: страницы, бандлы, стили, шрифты, KaTeX |
| `bun run build.ts --strict` | то же, но падает, если страница не на новой сборке |
| `bun run dev` | watch и локальный сервер на 8765 |
| `bunx tsc --noEmit` | строгая проверка типов |
| `bun run lint` | Biome: форматирование, линт и порядок импортов без записи |
| `bun run lint:fix` | то же с исправлением и переформатированием |
| `bun test` | юнит-тесты домена и гейты страниц |
| `bun run smoke` | каждая страница в headless Chromium: загрузка, тема, каталог |

`just lab-check` выполняет проверку типов, Biome, тесты и строгую сборку.
`just lab-smoke` гоняет браузерный прогон; для него один раз нужен браузер:

```sh
cd lab
bunx playwright install chromium
```

Biome проверяет TypeScript и JSON.
HTML и CSS исключены: разметку держат гейты страниц, вёрстку проверяет smoke, а формат HTML здесь ручной.
Правило `useTemplate` выключено: страницы собирают TeX-строки, где конкатенация с экранированными обратными слэшами читается лучше шаблонных литералов.

## Устройство

```
src/core/      DOM, биты, KaTeX, шапка сайта
src/domain/    логика высказываний, логика первого порядка, множества
src/pages/     страница: <name>.html и <name>.ts
src/static/    lab.css, шрифты, KaTeX
src/catalog.ts каталог лабораторий
tests/         bun test и smoke
```

- `<!-- @head -->` в странице раскрывается сборкой в тему, стили и KaTeX.
- Внизу страницы три скрипта: KaTeX, `site.js`, бандл страницы.
- Бандл собирается как IIFE и минифицируется; source maps кладутся рядом.
- Сетевых запросов нет: всё считается в браузере.

## Почему исходники лежат так

HTML и TypeScript одной страницы стоят рядом и называются одинаково.
HTML остаётся документом: заголовок, разметка панелей, подписи и тексты.
TypeScript остаётся точкой входа поведения и ничего не рисует до загрузки.
Сборка связывает пару по имени, поэтому страницу можно прочитать без фреймворка и без разметки, собранной из JS.

Стили лежат одним `lab.css`.
Токены, оболочка сайта и компоненты общие для всех страниц, а страничные блоки занимают малую часть файла.
Дробить его на несколько файлов при пятнадцати страницах смысла нет: браузер получил бы лишние запросы, а порядок каскада стал бы хрупким.
Если появится изоляция стилей на уровне компонентов, тогда и понадобится отдельный слой.

## Решения

**Сервер не нужен.** Все вычисления игрушечного масштаба: карта Карно до пяти переменных, DPLL на малых формулах, ROBDD, коды, замыкания малых матриц.
Сервер добавил бы задержку на каждое нажатие и точку отказа, не добавив вычислений.

**Классические скрипты, не ES-модули.** Это выбор ради отладки двойным щелчком по файлу.
Цена: общие модули дублируются в бандле каждой страницы, порядка десяти-пятнадцати KiB минифицированного JS.
Выигрыш в размере от общего чанка не виден на фоне шрифтов и KaTeX, а открытие по `file://` теряется сразу.

**Тема отдельным скриптом в `head`.** Иначе первый кадр рисуется светлым и страница мигает.

**Никакого фреймворка.** Пятнадцать независимых страниц с локальным состоянием, без роутинга и серверных данных.
Общий слой --- `core/`, он и держит повторение.

## Добавить лабораторию

1. `src/pages/<name>.html`: разметка, `<!-- @head -->`, три скрипта внизу.
2. `src/pages/<name>.ts`: поведение, импорты из `../core/*` и `../domain/*`.
3. Запись в `src/catalog.ts`.
4. `just lab-check`: гейты проверят каталог, скрипты, отсутствие глобальных пространств имён и существование всех `must("#id")`.

Правила дизайна и канон оформления лабораторий --- в `AGENTS.md`.
