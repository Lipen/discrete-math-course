# Лаборатории

Интерактивный стенд курса: восемнадцать лабораторий и каталог.
Исходники на TypeScript, выход --- статические файлы для GitHub Pages.

## Быстрый старт

```sh
cd lab
bun install
bun run dev        # http://localhost:8765, пересборка на изменение
```

Сборка без сервера:

```sh
just lab           # lab/dist
just site          # site/dist, включая lab
```

## Команды

| Команда | Что делает |
|---|---|
| `bun run build` | собирает `dist`: страницы, бандлы, стили, шрифты, KaTeX |
| `bun run build.ts --strict` | то же, но падает, если страница не на новой сборке |
| `bun run dev` | watch и локальный сервер на 8765 |
| `bunx tsc --noEmit` | строгая проверка типов |
| `bun test` | юнит-тесты домена и гейты страниц |
| `bun run smoke` | каждая страница в headless Chromium: загрузка, тема, каталог |

`just lab-check` выполняет проверку типов, тесты и строгую сборку.
`just lab-smoke` гоняет браузерный прогон; для него один раз нужен браузер:

```sh
cd lab
bunx playwright install chromium
```

## Устройство

```
src/core/      DOM, биты, KaTeX, шапка сайта
src/domain/    логика высказываний, логика первого порядка, множества
src/pages/     страница: <name>.html и <name>.ts
src/static/    lab.css, шрифты, KaTeX
src/catalog.ts каталог лабораторий
tests/         bun test и smoke
```

- `<!-- @head -->` в странице раскрывается сборкой в тему, стили и KaTeX.
- Внизу страницы три скрипта: KaTeX, `site.js`, бандл страницы.
- Бандл собирается как IIFE и минифицируется; source maps кладутся рядом.
- Сетевых запросов нет: всё считается в браузере.

## Решения

**Сервер не нужен.** Все вычисления игрушечного масштаба: карта Карно до пяти переменных, DPLL на малых формулах, ROBDD, коды, замыкания малых матриц.
Сервер добавил бы задержку на каждое нажатие и точку отказа, не добавив вычислений.

**Классические скрипты, не ES-модули.** Это выбор ради отладки двойным щелчком по файлу.
Цена: общие модули дублируются в бандле каждой страницы, порядка десяти-пятнадцати KiB минифицированного JS.
Выигрыш в размере от общего чанка не виден на фоне шрифтов и KaTeX, а открытие по `file://` теряется сразу.

**Тема отдельным скриптом в `head`.** Иначе первый кадр рисуется светлым и страница мигает.

**Никакого фреймворка.** Восемнадцать независимых страниц с локальным состоянием, без роутинга и серверных данных.
Общий слой --- `core/`, он и держит повторение.

## Добавить лабораторию

1. `src/pages/<name>.html`: разметка, `<!-- @head -->`, три скрипта внизу.
2. `src/pages/<name>.ts`: поведение, импорты из `../core/*` и `../domain/*`.
3. Запись в `src/catalog.ts`.
4. `just lab-check`: гейты проверят каталог, скрипты, отсутствие глобальных пространств имён и существование всех `must("#id")`.

Правила дизайна и канон оформления лабораторий --- в `AGENTS.md`.
