# combinatorics

Генераторы комбинаторных объектов.

Четыре семейства объектов — перестановки, сочетания, беспорядки и разбиения чисел — каждое перечисляется в лексикографическом порядке.
Каждое перечисление даёт ровно то количество, которое предсказывает теория: $n!$, $C(n, k)$ и субфакториал $!n$.

## Быстрый старт

```bash
cargo run --example permutations
cargo run --example combinations
cargo run --example derangements
cargo run --example partitions
cargo test
```

## Что генерирует крейт

| Семейство       | Объект                                      | Количество | Порядок перечисления |
| --------------- | ------------------------------------------- | ---------- | -------------------- |
| Перестановки    | список `0..n`, каждое значение один раз     | $n!$       | лексикографический   |
| Сочетания       | строго возрастающее `k`-подмножество `0..n` | $C(n, k)$  | лексикографический   |
| Беспорядки      | перестановка без неподвижных точек          | $!n$       | лексикографический   |
| Разбиения числа | невозрастающий список с суммой `n`          | $p(n)$     | лексикографический   |

### Количества

$C(n, k) = \binom{n}{k}$ — биномиальный коэффициент.
Субфакториал $!n$ подчиняется рекуррентности

$$!n = (n - 1) \cdot \bigl(!(n - 1) + !(n - 2)\bigr), \qquad !0 = 1,\ \ !1 = 0$$

Число разбиений $p(n)$ берётся из самого перечисления: крейт считает длину порождённого списка, а не вычисляет рекуррентность.

## Демо

| Демо           | Показывает                                                                       |
| -------------- | -------------------------------------------------------------------------------- |
| `permutations` | `next_permutation` на `(2, 4, 1, 3)`, все 6 перестановок `0..3`, количество $5!$ |
| `combinations` | 2-подмножества `0..4`, $C(10, 5) = 252$                                          |
| `derangements` | субфакториалы $!1..!6$, беспорядки `0..3`                                        |
| `partitions`   | числа разбиений $p(0)..p(10)$ по перечислению, разбиения числа 5                 |

## API

| Функция                                      | Результат                                                       |
| -------------------------------------------- | --------------------------------------------------------------- |
| `factorial(n)`                               | $n!$ (помещается в `u64` при $n \le 20$)                        |
| `next_permutation(&mut p)`                   | переводит `p` к следующей перестановке, `false` после последней |
| `permutations(n)`                            | все $n!$ перестановки `0..n`                                    |
| `binomial(n, k)`, `count_combinations(n, k)` | $C(n, k)$ (помещается в `u64` при $n \le 67$)                   |
| `combinations(n, k)`                         | все $C(n, k)$ `k`-подмножества `0..n`                           |
| `subfactorial(n)`                            | $!n$ (помещается в `u64` при $n \le 20$)                        |
| `derangements(n)`                            | все $!n$ беспорядка `0..n`                                      |
| `partitions(n)`                              | все $p(n)$ разбиений числа `n`                                  |

## Заметки

- `next_permutation` использует три классических шага: найти самый длинный убывающий суффикс, поменять опорный элемент с наименьшим большим элементом суффикса и обратить суффикс.
- Беспорядки перечисляются без неподвижных точек: на каждой позиции совпадающее значение пропускается.

## Тесты

`cargo test` запускает модульные тесты рядом с кодом в `src/` и межсемейные проверки в `tests/`.
Межсемейный файл проверяет, что каждое перечисление совпадает со своей формулой ($n!$, $C(n, k)$, $!n$), а число разбиений — с длиной перечисленного списка.
