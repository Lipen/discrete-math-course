# combinatorics

Генераторы комбинаторных объектов.

Четыре семейства объектов --- перестановки, сочетания, беспорядки и разбиения чисел --- каждое перечисляется в лексикографическом порядке. Количества в точности совпадают с теорией: `n!`, `C(n, k)` и субфакториал `!n`. Число разбиений считается по длине перечисления, а не по `p(n)` Эйлера. У каждой идеи есть запускаемое демо в `examples/`.

## Быстрый старт

```bash
cargo run -p combinatorics --example permutations
cargo run -p combinatorics --example combinations
cargo run -p combinatorics --example derangements
cargo run -p combinatorics --example partitions
cargo test -p combinatorics
```

## Что генерирует крейт

Каждое семейство перечисляется в лексикографическом порядке. Тесты проверяют, что каждое перечисление даёт ровно соответствующую формулу: `n!`, `C(n, k)` и `!n`. Разбиения числа проверяются подсчётом перечисленного списка.

| Семейство | Объект | Количество | Порядок перечисления |
| --- | --- | --- | --- |
| Перестановки | список `0..n`, каждое значение один раз | `n!` | лексикографический |
| Сочетания | строго возрастающее `k`-подмножество `0..n` | `C(n, k)` | лексикографический |
| Беспорядки | перестановка без неподвижных точек | `!n` | лексикографический |
| Разбиения числа | невозрастающий список, суммирующийся до `n` | по длине перечисления | лексикографический |

## API

| Модуль | Функции |
| --- | --- |
| `permutation` | `next_permutation`, `permutations`, `factorial` |
| `combination` | `combinations`, `binomial`, `count_combinations` |
| `derangement` | `derangements`, `subfactorial` |
| `partition` | `partitions` |

## Демо

| Демо | Показывает |
| --- | --- |
| `permutations` | `next_permutation` на `(2,4,1,3)`; все 6 перестановок `0..3`; количество `5!` |
| `combinations` | 2-подмножества `0..4`; `C(10,5) = 252` |
| `derangements` | Субфакториалы `!1..!6`; беспорядки `0..3` |
| `partitions` | Числа разбиений `p(0)..p(10)` по перечислению; разбиения числа 5 |

## Заметки

- `next_permutation` использует три классических шага: найти самый длинный убывающий суффикс, поменять местами опорный элемент с наименьшим большим элементом суффикса и обратить суффикс.
- Беспорядки перечисляются без неподвижных точек: на каждой позиции совпадающее значение пропускается.
- Количества имеют тип `u64`: `n!` помещается при `n <= 20`, `C(n, k)` при `n <= 67`, а `!n` при `n <= 20`.

## Тесты

```bash
cargo test -p combinatorics
```

Модульные тесты находятся рядом с кодом в `src/`; межсемейные проверки того, что каждое перечисление совпадает со своей формулой (`n!`, `C(n, k)`, `!n`), а число разбиений --- с длиной перечисления, находятся в `tests/`.
