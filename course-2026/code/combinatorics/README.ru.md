# combinatorics

Генераторы комбинаторных объектов.

Четыре семейства объектов --- перестановки, сочетания, беспорядки и разбиения чисел --- каждое перечисляется в лексикографическом порядке и снабжено биекцией ранг/де-ранг. Количества в точности совпадают с теорией: `n!`, `C(n, k)`, субфакториал `!n` и число разбиений `p(n)`. У каждой идеи есть запускаемое демо в `examples/`.

## Быстрый старт

```bash
cargo run -p combinatorics --example permutations
cargo run -p combinatorics --example combinations
cargo run -p combinatorics --example derangements
cargo run -p combinatorics --example partitions
cargo test -p combinatorics
```

## Что генерирует крейт

Ранг сопоставляет каждому объекту его позицию в лексикографическом перечислении, начиная с 0. Де-ранг возвращает объект по заданному рангу. Вместе они образуют биекцию: `rank(unrank(r)) == r` и `unrank(rank(x)) == x`. Тесты проверяют, что каждое перечисление даёт ровно соответствующую формулу.

| Семейство | Объект | Количество | Порядок перечисления | Ранг/де-ранг |
| --- | --- | --- | --- | --- |
| Перестановки | список `0..n`, каждое значение один раз | `n!` | лексикографический | факториальная система счисления |
| Сочетания | строго возрастающее `k`-подмножество `0..n` | `C(n, k)` | лексикографический | вычитание префиксных блоков |
| Беспорядки | перестановка без неподвижных точек | `!n` | лексикографический | мемоизированный подсчёт дополнений |
| Разбиения числа | невозрастающий список, суммирующийся до `n` | `p(n)` | лексикографический | подсчёт ограниченных частей |

## API

| Модуль | Функции |
| --- | --- |
| `permutation` | `next_permutation`, `permutations`, `factorial`, `rank_permutation`, `unrank_permutation` |
| `combination` | `combinations`, `binomial`, `count_combinations`, `rank_combination`, `unrank_combination` |
| `derangement` | `derangements`, `subfactorial`, `rank_derangement`, `unrank_derangement` |
| `partition` | `partitions`, `partition_count`, `rank_partition`, `unrank_partition` |

## Демо

| Демо | Показывает |
| --- | --- |
| `permutations` | `next_permutation` на `(2,4,1,3)`; все 6 перестановок `0..3`; ранг/де-ранг по `0..4` |
| `combinations` | 2-подмножества `0..4`; `C(10,5) = 252`; ранг/де-ранг по 3-подмножествам `0..5` |
| `derangements` | Субфакториалы `!1..!6`; беспорядки `0..3`; ранг/де-ранг по `0..4` |
| `partitions` | Числа разбиений `p(0)..p(10)` с `p(10) = 42`; разбиения числа 5; ранг/де-ранг |

## Заметки

- `next_permutation` использует три классических шага: найти самый длинный убывающий суффикс, поменять местами опорный элемент с наименьшим большим элементом суффикса и обратить суффикс.
- Беспорядки перечисляются без неподвижных точек: на каждой позиции совпадающее значение пропускается.
- `p(n)` использует пятиугольную рекуррентность Эйлера. Ранжирование беспорядков и разбиений подсчитывает дополнения с мемоизацией, поэтому не материализует весь список.
- Количества имеют тип `u64`: `n!` помещается при `n <= 20`, `C(n, k)` при `n <= 67`, `!n` при `n <= 20`, а `p(n)` при `n <= 300`-иш.

## Тесты

```bash
cargo test -p combinatorics
```

Модульные тесты находятся рядом с кодом в `src/`; межсемейные проверки того, что каждое перечисление совпадает со своей формулой и каждая пара ранг/де-ранг является биекцией, находятся в `tests/`.
