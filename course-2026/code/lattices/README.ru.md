# lattices

Решётки и частичные порядки.

Конечные решётки с явным порядком, объединение (супремум) и пересечение (инфимум) пары, а также ключевые структурные свойства --- дистрибутивность, модулярность и характеристика Биркгофа о том, что решётка дистрибутивна ровно тогда, когда она не содержит подрешётки, изоморфной M3 (ромб) или N5 (пятиугольник).

## Быстрый старт

```bash
cargo run -p lattices --example join_meet
cargo run -p lattices --example birkhoff
cargo test -p lattices
```

## Идея

Решётка --- это конечное множество с частичным порядком, в котором каждая пара элементов имеет объединение (супремум: наименьшая верхняя грань) и пересечение (инфимум: наибольшая нижняя грань).

- Решётка *дистрибутивна*, когда `a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)` для каждой тройки.
- Решётка *модулярна*, когда `a ∨ (b ∧ c) = (a ∨ b) ∧ c` всякий раз, когда `a ≤ c`.
- *Характеристика Биркгофа*: дистрибутивна ⇔ нет подрешётки, изоморфной M3 или N5. Ромб M3 модулярен, но не дистрибутивен; пятиугольник N5 даже не модулярен.

Крейт проверяет законы напрямую, а также ищет запрещённые подрешётки, так что характеристику можно проверить на примерах.

## Демо

| Демо | Что показывает |
|------|---------------|
| `join_meet` | Верхние/нижние грани и объединение/пересечение на делителях числа 12: объединение {2,3} равно 6, пересечение равно 1; также перестраивает частично упорядоченное множество с помощью `relation_pairs` и печатает его диаграмму Хассе |
| `birkhoff` | Дистрибутивность и модулярность D₁₂, B₃, M3 и N5, плюс поиск подрешётки M3/N5 |

## API

| Элемент | Что делает |
|------|--------------|
| `Lattice` | Конечная решётка: `elements` плюс отношение `<=` |
| `le(a, b)` | Верно ли, что `a <= b` |
| `join(a, b)` / `meet(a, b)` | Супремум / инфимум пары, `Option`, если отсутствует |
| `is_lattice()` | Есть ли у каждой пары объединение и пересечение |
| `is_chain()` | Сравнима ли каждая пара |
| `is_distributive()` / `is_modular()` | Проверить законы решётки |
| `has_m3_sublattice()` / `has_n5_sublattice()` | Поиск запрещённой подрешётки |
| `is_distributive_birkhoff()` | Характеристика Биркгофа как одна проверка |
| `relation_pairs(n, leq)` | Отношение `{(i, j) : leq(i, j)}` как явный список пар |
| `hasse(pairs)` | Диаграмма Хассе (отношение покрытия): транзитивные пары удалены, строгая форма |
| `hasse_reflexive(pairs)` | То же самое, но сохраняет рефлексивные пары, чтобы соответствовать формату пар `Lattice` |
| `examples::m3()`, `n5()`, `divisors_12()`, `boolean_3()` | Сквозные примеры |
