# lattices

Решётки и частичные порядки.

Конечные решётки с явно заданным порядком, объединение (супремум) и пересечение (инфимум) пары.
Из структурных свойств проверяются дистрибутивность, модулярность и характеристика Биркгофа: решётка дистрибутивна ровно тогда, когда она не содержит подрешётки, изоморфной M3 (ромб) или N5 (пятиугольник).

## Быстрый старт

```bash
cargo test
cargo run --example join_meet
cargo run --example birkhoff
```

## Идея

Решётка — это конечное множество с частичным порядком, в котором у каждой пары элементов есть объединение и пересечение:

$$a \vee b = \sup\{a, b\} \qquad a \wedge b = \inf\{a, b\}$$

Объединение — наименьшая верхняя грань пары, пересечение — наибольшая нижняя грань.

- Решётка *дистрибутивна*, когда $a \wedge (b \vee c) = (a \wedge b) \vee (a \wedge c)$ для каждой тройки.
- Решётка *модулярна*, когда $a \vee (b \wedge c) = (a \vee b) \wedge c$ всякий раз, когда $a \le c$.
- *Характеристика Биркгофа*: дистрибутивна тогда и только тогда, когда нет подрешётки, изоморфной M3 или N5.
  Ромб M3 модулярен, но не дистрибутивен.
  Пятиугольник N5 даже не модулярен.

Крейт проверяет законы напрямую и вдобавок ищет запрещённые подрешётки, так что характеристику можно проверить на встроенных примерах.

## Демо

| Демо        | Что показывает                                                                      |
| ----------- | ----------------------------------------------------------------------------------- |
| `join_meet` | Верхние и нижние грани, объединение и пересечение пар в решётке делителей числа 12  |
| `birkhoff`  | Дистрибутивность и модулярность `D_12`, `B_3`, M3 и N5, плюс поиск подрешётки M3/N5 |

`join_meet` печатает верхние и нижние грани, объединение и пересечение нескольких пар решётки делителей числа 12: объединение $\{2, 3\}$ равно 6, пересечение равно 1.
Вторая часть порождает то же частично упорядоченное множество из предиката делимости и сводит его к диаграмме Хассе — отношению покрытия.
`birkhoff` прогоняет обе проверки дистрибутивности на четырёх сквозных примерах и подтверждает, что законы и поиск запрещённых подрешёток согласуются.

## API

### Методы `Lattice`

| Элемент                                       | Что делает                                                            |
| --------------------------------------------- | --------------------------------------------------------------------- |
| `Lattice`                                     | Конечная решётка: `elements` плюс отношение `<=` как явный список пар |
| `le(a, b)`                                    | Верно ли, что `a <= b`                                                |
| `upper_bounds(a, b)` / `lower_bounds(a, b)`   | Общие верхние / нижние грани пары                                     |
| `join(a, b)` / `meet(a, b)`                   | Супремум / инфимум пары, `None`, если отсутствует                     |
| `is_lattice()`                                | Есть ли у каждой пары объединение и пересечение                       |
| `bottom()` / `top()`                          | Наименьший / наибольший элемент, если есть                            |
| `is_chain()`                                  | Сравнима ли каждая пара                                               |
| `is_distributive()` / `is_modular()`          | Законы решётки, проверяемые для каждой тройки                         |
| `has_m3_sublattice()` / `has_n5_sublattice()` | Поиск запрещённой подрешётки                                          |
| `is_distributive_birkhoff()`                  | Характеристика Биркгофа как одна проверка                             |

### Предикаты и диаграммы Хассе

| Элемент                                                  | Что делает                                                                     |
| -------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `relation_pairs(n, leq)`                                 | Отношение `{(i, j) : leq(i, j)}` как явный список пар                          |
| `hasse(pairs)`                                           | Диаграмма Хассе (отношение покрытия): транзитивные и рефлексивные пары удалены |
| `hasse_reflexive(pairs)`                                 | То же, но с рефлексивными парами, чтобы совпадал формат пар `Lattice`          |
| `examples::m3()`, `n5()`, `divisors_12()`, `boolean_3()` | Сквозные примеры                                                               |

## Тесты

| Пример            | Модулярна | Дистрибутивна |
| ----------------- | :-------: | :-----------: |
| делители числа 12 | да        | да            |
| булеан `B_3`      | да        | да            |
| ромб M3           | да        | нет           |
| пятиугольник N5   | нет       | нет           |

Юнит-тесты проверяют ровно это на четырёх сквозных примерах, а поиск Биркгофа согласуется с законом дистрибутивности на всех четырёх.
