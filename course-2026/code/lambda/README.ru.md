# lambda

Бестиповое λ-исчисление.

Термы, подстановка без захвата, β-редукция при трёх стратегиях
(нормальный порядок, аппликативный порядок, слабая головная нормальная форма), кодировки Чёрча
(числа, булевы значения, пары), известные комбинаторы (SKI, Ω), комбинаторы неподвижной точки
(Y, Z) с факториалом, построенным на Z, и крошечный просто типизированный
слой.

## Быстрый старт

```bash
cargo run -p lambda --example church_arith
cargo run -p lambda --example combinators
cargo run -p lambda --example beta_trace
cargo run -p lambda --example fixpoint
cargo test -p lambda
```

## Основная операция

β-редукция подаёт аргумент в связыватель, заменяя каждое свободное вхождение связанной переменной:

$$ (\lambda x.\; M)\; N \;\to_\beta\; M[x := N] $$

Подстановка выполняется без захвата: когда свободная переменная $N$ могла бы быть захвачена связывателем, связыватель сначала α-переименовывается.

![Бета-редукция комбинатора K](assets/beta-reduction.svg)

На схеме шаг за шагом редуцируется комбинатор-константа: $(\lambda x.\,\lambda y.\,x)\;a\;b$.

## Стратегии редукции

Все драйверы ограничены топливом (`max_steps`), поэтому расходящиеся термы вроде Ω не могут
подвесить процесс, и сообщают о своём прогрессе как `Reduction` со счётчиком
шагов.

- **Нормальный порядок** (самый левый внешний) --- если нормальная форма существует, нормальный
  порядок её находит.
- **Аппликативный порядок** (самый левый внутренний) --- сначала вычисляет аргументы;
  может зациклиться там, где нормальный порядок завершается, например на `(λx. y) Ω`.
- **Слабая головная нормальная форма** --- останавливается, как только головка является переменной или
  связывателем; редексы внутри аргументов не трогаются.

## Неподвижные точки

Рекурсия в λ-исчислении --- это *неподвижная точка*: `X` с `X = F X`. Комбинатор
вызова по имени `Y = λf. (λx. f (x x)) (λx. f (x x))` разворачивается как
`Y F -> F (Y F)`. Комбинатор вызова по значению `Z = λf. (λx. f (λv. x x v))
(λx. f (λv. x x v))` добавляет обёртку `λv`, так что рекурсивное развёртывание
откладывается до появления аргумента. Факториал `fact = Z Fact` вычисляет
`3! = 6` примерно за 1500 чистых β-шагов (наивная подстановка экспоненциальна ---
реальные реализации совместно используют подтермы).

## Демо

| Демо | Что показывает |
|------|-------|
| `church_arith` | Числа Чёрча: succ, add, mult, power (2^4 = 16 и т. д.) |
| `combinators` | Комбинаторы I, K, S; SKK = I; незавершение Ω |
| `beta_trace` | Пошаговый след редукции; Ω с ограничением шагов; арифметика Чёрча со следом |
| `fixpoint` | Y разворачивается как `Y K -> K (Y K) -> λx. x`; факториал через Z |
