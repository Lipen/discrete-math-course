# lambda

Бестиповое лямбда-исчисление.

## Компоненты

- `Term` --- термы: переменные, абстракции, применения.
- Подстановка без захвата переменных и бета-редукция.
- Числа Чёрча и арифметика на них.

## Примеры

```bash
cargo run -p lambda --example church_arith
```

## Тесты

```bash
cargo test -p lambda
```
