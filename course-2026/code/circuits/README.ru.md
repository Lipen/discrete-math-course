# circuits

Комбинационные схемы как DAG из вентилей.

Схема --- это ориентированный ациклический граф: источниками служат первичные входы и константы 0/1, внутренние узлы --- логические вентили (AND, OR, XOR, NOT), а стоками --- выходы.
Поскольку вентиль ссылается только на более ранние узлы, построитель хранит граф в топологическом порядке, и ацикличность выполняется по построению.
Симуляция схемы --- это один упорядоченный проход; её измерение даёт два ресурса, между которыми каждый инженер ищет компромисс --- **размер** (число вентилей, площадь чипа) и **глубина** (самый длинный путь от входа к выходу, задержка сигнала).

Сквозной пример --- сложение: полусумматор, полный сумматор и цепочка, объединяющая `n` полных сумматоров в `n`-битный сумматор с последовательным переносом.
Перенос проходит через каждый бит, поэтому размер и глубина растут линейно с разрядностью --- компактная, честная база.

## Быстрый старт

```bash
cargo run -p circuits --example half_adder
cargo run -p circuits --example ripple_carry
cargo run -p circuits --example fuzz
cargo test -p circuits
```

## Как это работает

Создайте `Circuit`, задайте его источники, затем объединяйте их в вентили.
Каждый конструктор возвращает `NodeId`, на который могут ссылаться последующие вентили, так что один выход может питать много входов (fan-out).

```rust
use circuits::Circuit;

let mut c = Circuit::new();
let x = c.input(0);
let y = c.input(1);
let z = c.input(2);
// Размер 3, глубина 2: AND и NOT параллельны, затем OR ждёт оба.
let f = c.or(c.and(x, y), c.not(z));
assert_eq!(c.size(), 3);
assert_eq!(c.depth(), 2);
assert!(c.eval(f, &[true, true, false]).unwrap());
```

![Полусумматор: XOR для суммы, AND для переноса](assets/half-adder.svg)

Полный сумматор состоит из пяти вентилей (два XOR, два AND, один OR) и вычисляет `S = A XOR B XOR Cin`, `Cout = majority(A, B, Cin)`.
Объединение `n` полных сумматоров даёт сумматор с последовательным переносом.

## API

| Элемент | Назначение |
| --- | --- |
| `Circuit::new` | Свежая пустая схема |
| `Circuit::input(i)` | `i`-й первичный вход (создаётся один раз, затем переиспользуется) |
| `Circuit::constant(v)` / `zero` / `one` | Константы 0/1 |
| `Circuit::and` / `or` / `xor` / `not` | Добавить вентиль и вернуть его `NodeId` |
| `Circuit::size` | Число вентилей (площадь) |
| `Circuit::depth` / `node_depth` | Самый длинный путь от входа к выходу (задержка) |
| `Circuit::simulate` / `eval` | Один топологический проход для вычисления всех выходов |
| `half_adder` | `S = A XOR B`, `C = A AND B` |
| `full_adder` | `S = A XOR B XOR Cin`, `Cout` = функция большинства |
| `ripple_carry_adder(n)` | Цепочка из `n` полных сумматоров; размер и глубина `O(n)` |
| `Adder::add` / `add_exact` / `add_bits` | Вычислить сумматор для целых чисел или битовых срезов |
| `bits_of` / `value_of` | Преобразование между целыми числами и битовыми срезами от младшего бита к старшему |

## Демо

| Демо | Что показывает |
| --- | --- |
| `half_adder` | Таблицы истинности полусумматора и полного сумматора, с размером и глубиной |
| `ripple_carry` | Книжная трасса `0111 + 0001 = 1000`, затем более широкая сумма, сверенная с арифметикой |
| `fuzz` | Случайные операнды на многих битовых ширинах, сверенные с целочисленным сложением |

## Тесты

```bash
cargo test -p circuits
```

Модульные тесты покрывают таблицы истинности полусумматора и полного сумматора, размер и глубину (включая правило, что параллельные ветви считаются один раз), переиспользование входов и констант, ошибки отсутствующих входов, книжную 4-битную трассу с последовательным переносом, сверку сумматора с последовательным переносом против целочисленной арифметики, а также преобразования битов.
