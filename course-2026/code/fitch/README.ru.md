# fitch

Программа проверки доказательств в натуральной дедукции в стиле Фитча для пропозициональной логики.

Доказательство --- это плоский список из `Step`; каждый шаг несёт формулу, глубину вложенности (0 = основное доказательство, 1 = внутри одного поддоказательства, ...) и обоснование: допущение или правило, применённое к более ранним строкам.
Программа проверки проверяет, что каждое умозаключение является корректным применением своего правила и что каждая цитируемая строка всё ещё находится в области видимости --- строку внутри разряженного поддоказательства больше нельзя использовать.

## Быстрый старт

```bash
cargo run -p fitch --example contrapositive
cargo run -p fitch --example rejected
cargo test -p fitch
```

## Идея

Натуральная дедукция формализует математическое доказательство как игру правил введения и исключения: чтобы доказать `A -> B`, допустите `A` в поддоказательстве и выведите `B`; чтобы использовать `A -> B`, соедините его с `A` и заключите `B`.
Диаграммы Фитча изображают поддоказательства как вложенные рамки; здесь вложенность --- это поле `depth`.
Набор правил полон для классической пропозициональной логики: исключение двойного отрицания (`Dne`) --- единственный классический шаг, всё остальное интуиционистски общезначимо --- то же разделение, которое книга проводит между конструктивным и классическим рассуждением.

## Демо

| Демо | Что показывает |
|------|---------------|
| `contrapositive` | Строит и проверяет доказательство `(P -> Q) -> (~Q -> ~P)` с двумя вложенными поддоказательствами |
| `rejected` | Два некорректных доказательства --- неверный дизъюнкт и строка вне области видимости --- и ошибка, которую каждое вызывает |

## API

| Элемент | Что делает |
|------|--------------|
| `Formula` | Пропозициональная формула: `Atom`, `Bottom`, `Not`, `And`, `Or`, `Implies` |
| `atom`, `bottom`, `not`, `and`, `or`, `implies` | Конструкторы формул |
| `Step { depth, formula, just }` | Одна строка доказательства |
| `Just` | `Assumption` плюс правила: введение/исключение конъюнкции, введение/исключение дизъюнкции, введение/исключение импликации, введение/исключение отрицания, исключение лжи, исключение двойного отрицания |
| `check(&[Step]) -> Result<(), Error>` | Проверяет каждый шаг; `Error` называет нарушающую строку и причину |

Формулы строятся конструкторами и выводятся в обычной записи:

```rust
use fitch::{atom, implies, not};

let p = atom("P");
let q = atom("Q");
let contra = implies(implies(p.clone(), q.clone()), implies(not(q), not(p)));
assert_eq!(contra.to_string(), "((P -> Q) -> (¬Q -> ¬P))");
```

Доказательства проверяются строка за строкой:

```rust
use fitch::{atom, check, or, Just, Step};

// P ⊢ P ∨ Q by ∨-introduction.
let steps = vec![
    Step { depth: 0, formula: atom("P"), just: Just::Assumption },
    Step { depth: 0, formula: or(atom("P"), atom("Q")), just: Just::OrIntroLeft { disj: 1 } },
];
assert!(check(&steps).is_ok());
```
