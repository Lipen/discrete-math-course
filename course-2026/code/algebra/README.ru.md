# algebra

Алгебраические структуры как типажи Rust: полугруппа, моноид, группа, кольцо, поле --- плюс гомоморфизмы групп и факторгруппы, а также конечные поля `GF(2^m)`.

Иерархия повторяет главу книги об алгебре. Нижний слой построен с нуля --- натуральные числа Пеано и написанный вручную алгоритм Евклида --- а конкретные экземпляры (классы вычетов, перестановки, булево поле) опираются на типажи и используют стандартные итераторы.

## Быстрый старт

```bash
cargo run -p algebra --example from_scratch
cargo run -p algebra --example groups
cargo run -p algebra --example rings
cargo run -p algebra --example cayley
cargo run -p algebra --example homomorphism
cargo run -p algebra --example finite_field
cargo test -p algebra
```

## Идея

`Semigroup` --- это множество с ассоциативной операцией `op`; `Monoid` добавляет нейтральный элемент; `Group` добавляет обратный элемент. `Ring` соединяет аддитивную группу с ассоциативным умножением, а `Field` --- это кольцо, в котором каждый ненулевой элемент обратим.

Слой «с нуля» делает эти определения конкретными до появления какого-либо встроенного числового типа: `Nat` --- это определение Пеано (только `Zero` и `Succ`), а `gcd` / `extended_gcd` --- это написанный вручную алгоритм Евклида, который позже даёт модулярные обратные. Затем экземпляры используют стандартные итераторы.

## Демо

| Демо | Что показывает |
|------|---------------|
| `from_scratch` | Сложение и умножение Пеано, написанные вручную gcd и модулярный обратный |
| `groups` | Вычеты по модулю 8, перестановки, группа единиц Z_8^*: порядки, степени, подгруппы |
| `rings` | Делители нуля в Z_6, единицы Z_5, поле GF(2) |
| `cayley` | Таблица Кэли для Z_4 и свойство латинского квадрата |
| `dihedral` | D_4: порядки, таблица Кэли, некоммутативность, подгруппа поворотов |
| `table_group` | Группа как чистые данные: проверки аксиом и контрпример не-группы |
| `homomorphism` | Отображение Z_6 -> Z_3, его ядро и смежные классы, первая теорема об изоморфизме |
| `finite_field` | Таблицы сложения/умножения для GF(4), примитивный элемент, порядки GF(256) |

## API

| Элемент | Что делает |
|------|--------------|
| `Semigroup`, `Monoid`, `Group` | Иерархия с одной операцией (`op`, `identity`, `inverse`) |
| `Ring`, `Field` | Иерархия с двумя операциями (`add`, `mul`, `neg`, `inv`) |
| `Zn<N>` | Классы вычетов по модулю N: аддитивная группа и кольцо |
| `Unit<N>` | Единицы Z_N: мультипликативная группа Z_N^* |
| `Perm<N>` | Перестановки N элементов: симметрическая группа S_N |
| `Bool` | GF(2): булевы значения с XOR и AND, наименьшее поле |
| `Nat` | Натуральные числа Пеано (с нуля) |
| `gcd`, `extended_gcd`, `mod_inverse` | Написанный вручную алгоритм Евклида |
| `power`, `order`, `subgroup`, `is_abelian` | Общие вспомогательные функции для групп |
| `Type` | Типы как данные: полукольцо типов с `cardinality` и `simplify` |
| `Zero`, `One`, `Sum`, `Prod` | Полукольцо на уровне типов: `0`, `1`, `+`, `*` с доказательствами изоморфизма |
| `BoolSet<T>` | Булеан как булево кольцо: симметрическая разность и пересечение |
| `Category`, `Hask`, `compose`, `id` | Категория множеств: функции как морфизмы |
| `curry`, `uncurry`, `constant`, `flip` | Экспоненциалы и комбинаторы морфизмов |
| `Functor`, `Fix`, `OptionF`, `cata` | Функторы и неподвижные точки: `Nat = Fix(Option)` |
| `D4` | Диэдральная группа порядка 8: симметрии квадрата |
| `TableGroup` | Конечная группа, заданная только своей таблицей Кэли, с проверками аксиом |
| `is_homomorphism`, `kernel`, `image` | Сохраняющие структуру отображения между группами и их инварианты |
| `left_cosets`, `is_normal`, `coset_product` | Смежные классы, нормальность и операция факторгруппы |
| `Gf<M, MOD>`, `Gf4`, `Gf256` | Конечные поля `GF(2^m)`: GF(4) и байтовое поле AES |
