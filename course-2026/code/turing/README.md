# turing

Машины Тьюринга.

## Компоненты

- `Tape` --- лента с головкой.
- `Machine` --- таблица переходов, принимающие и отвергающие состояния.
- Примеры машин: язык 0^n1^n и слова, заканчивающиеся на 0.

## Примеры

```bash
cargo run -p turing --example zero_n_one_n
```

## Тесты

```bash
cargo test -p turing
```
