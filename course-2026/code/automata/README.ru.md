# automata

Конечные автоматы и регулярные языки.

ДКА, НКА с ε-переходами, конструкция подмножеств и операции над языками (дополнение, объединение, пересечение, разность).
У каждой идеи есть запускаемое демо в `examples/`.

## Быстрый старт

```bash
cargo run -p automata --example even_ones
cargo test -p automata
```

## Что распознаёт ДКА

ДКА --- это кортеж $(Q, \Sigma, \delta, q_0, F)$.
Он принимает слово $w$, когда расширенная функция переходов попадает в принимающее состояние:

$$ L(M) = \{ w \in \Sigma^* \mid \hat\delta(q_0, w) \in F \} $$

![ДКА для чётного числа единиц](assets/dfa-even-ones.svg)

На схеме показан наименьший полезный пример: слова над $\{0, 1\}$ с чётным числом `1`.
Состояние $q_0$ является одновременно начальным и единственным принимающим; чтение `1` переключает его, чтение `0` оставляет его.

## API

| Тип | Назначение | Ключевые методы |
| --- | --- | --- |
| `Dfa` | Детерминированный автомат | `accepts`, `is_empty`, `equivalent_to`, `complete`, `complement`, `union`, `intersection`, `difference` |
| `Nfa` | Недетерминированный автомат (с ε-переходами) | `epsilon_closure`, `accepts`, `to_dfa` |

## Демо

| Демо | Что показывает |
| --- | --- |
| `even_ones` | ДКА для чётного числа `1`, проверенный слово за словом |
| `nfa_to_dfa` | Конструкция подмножеств на НКА «содержит `00` или `11`» |
| `language_ops` | Дополнение, объединение, пересечение, разность на двух ДКА |

## Тесты

```bash
cargo test -p automata
```

Модульные тесты лежат рядом с кодом в `src/`.
Запустите `cargo test -p automata`, чтобы также увидеть doc-тесты, покрывающие каждый публичный метод.
