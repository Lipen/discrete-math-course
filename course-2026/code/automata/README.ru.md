# automata

Конечные автоматы и регулярные языки.

Детерминированные и недетерминированные автоматы над алфавитами из `char`, конструкция подмножеств и классические операции над языками — дополнение, объединение, пересечение, разность.
У каждой идеи есть запускаемое демо в `examples/`.

## Быстрый старт

```bash
cargo test
cargo run --example even_ones
```

## Модель

### ДКА

ДКА — это кортеж $(Q, \Sigma, \delta, q_0, F)$.
Он принимает слово $w$, когда расширенная функция переходов попадает в принимающее состояние:

$$ L(M) = \{ w \in \Sigma^* \mid \hat\delta(q_0, w) \in F \} $$

![ДКА для чётного числа единиц](assets/dfa-even-ones.svg)

На схеме показан наименьший полезный пример: слова над $\{0, 1\}$ с чётным числом `1`.
Состояние $q_0$ одновременно начальное и единственное принимающее.
Чтение `1` переключает его, чтение `0` оставляет на месте.

Переходы хранятся таблицей, а отсутствующая ячейка — неявная ловушка: попадание в неё отвергает слово.

### НКА

НКА ослабляет детерминированность в трёх направлениях:

|            | ДКА                        | НКА                                     |
| ---------- | -------------------------- | --------------------------------------- |
| по символу | ровно один переход         | любое число переходов                   |
| бесплатно  | ничего                     | ε-переходы, не читающие символа         |
| принятие   | чтение заканчивается в $F$ | хотя бы одно чтение заканчивается в $F$ |

$$ L(N) = \{ w \in \Sigma^* \mid \hat\delta(E(\{q_0\}), w) \cap F \neq \varnothing \} $$

Здесь $E(S)$ — ε-замыкание: все состояния, достижимые из $S$ по ε-переходам, включая само $S$.

### Конструкция подмножеств

Конструкция подмножеств переводит НКА в эквивалентный ДКА, состояния которого — ε-замкнутые множества состояний НКА:

$$ \delta'(R, a) = E\left( \bigcup_{q \in R} \delta(q, a) \right) $$

Состояние ДКА принимающее, когда его множество содержит принимающее состояние НКА.
Переход в пустое множество остаётся неопределённым, и ДКА трактует его как ловушку.

## Демо

| Демо           | Что показывает                                                                          |
| -------------- | --------------------------------------------------------------------------------------- |
| `even_ones`    | ДКА для чётного числа `1`, проверка слово за словом                                     |
| `nfa_to_dfa`   | Конструкция подмножеств на НКА для слов с `00` или `11`, со сверкой ответов             |
| `language_ops` | Дополнение, объединение, пересечение и разность двух ДКА через конструкцию произведения |

`nfa_to_dfa` детерминирует НКА из пяти состояний в ДКА и сравнивает обе машины на каждом тестовом слове.
Вердикт `ok` в каждой строке подтверждает, что конструкция подмножеств сохранила язык.

## API

| Тип   | Назначение                                 | Ключевые методы                                                                                         |
| ----- | ------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| `Dfa` | Детерминированный автомат                  | `accepts`, `is_empty`, `equivalent_to`, `complete`, `complement`, `union`, `intersection`, `difference` |
| `Nfa` | Недетерминированный автомат с ε-переходами | `epsilon_closure`, `accepts`, `to_dfa`                                                                  |

## Тесты

Модульные тесты лежат рядом с кодом в `src/`.
Они проверяют принятие слово за словом, отвержение символов вне алфавита, пустоту языка, закон дополнения $\overline{\overline{L}} = L$, объединение, пересечение и разность против алгебры множеств, эквивалентность структурно разных машин с одним языком и законы ε-замыкания.
Doc-тесты покрывают каждый публичный метод.
