# matroids

Матроиды и жадный алгоритм.

Аксиомы независимости, три матроида (графический, линейный над GF(2), равномерный), матроид планирования, функция ранга и ключевой факт, что жадный алгоритм оптимален ровно тогда, когда система независимости является матроидом. Демо-контрпример показывает, как жадный алгоритм терпит неудачу на не-матроиде.

## Быстрый старт

```bash
cargo run -p matroids --example counterexample
cargo run -p matroids --example spanning
cargo run -p matroids --example scheduling
cargo run -p matroids --example linear
cargo run -p matroids --example rank
cargo test -p matroids
```

## Идея

Матроид --- это основное множество с семейством независимых множеств, удовлетворяющим двум аксиомам:

- *Наследственность*: каждое подмножество независимого множества независимо.
- *Обмен*: если `A` и `B` независимы и `|B| > |A|`, то некоторый элемент из `B \ A` можно добавить в `A`, сохранив его независимым.

На матроиде жадный алгоритм (брать элементы в порядке убывания веса, пока сохраняется независимость) находит независимое множество максимального веса. На любой другой системе независимости жадный алгоритм можно обмануть.

## Демо

| Демо | Что показывает |
|------|---------------|
| `counterexample` | Жадный алгоритм берёт `{a}` (вес 5), тогда как оптимум `{b,c}` весит 8: отсутствует свойство обмена |
| `spanning` | Краскал как жадный алгоритм на графическом матроиде: максимальное остовное дерево треугольника, вес 9 |
| `scheduling` | Задания со сроками как матроид: жадный алгоритм выбирает `{A,C}` с прибылью 80 |
| `linear` | Линейный матроид над GF(2): три вектора, жадный алгоритм выбирает `{v1,v2}` с весом 9 |
| `rank` | Ранг графического, линейного и равномерного матроидов: все равны 2 |

## API

| Элемент | Что делает |
|------|--------------|
| `Matroid` trait | `n()` + `is_independent(&[u32]) -> bool` |
| `greedy(m, weights)` | Независимое множество максимального веса на матроиде |
| `rank(m)` | Размер максимального независимого множества (через жадный алгоритм с единичными весами) |
| `UniformMatroid`, `GraphicMatroid`, `BinaryLinearMatroid`, `SchedulingMatroid` | Три матроида плюс матроид планирования |
| `SimpleIndependenceSystem` | Не-матроид, чтобы показать, что жадный алгоритм может потерпеть неудачу |
