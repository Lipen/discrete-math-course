# matroids

Матроиды и жадный алгоритм.

Аксиомы независимости, три конкретных матроида (графический, линейный над GF(2), равномерный), матроид планирования, функция ранга и ключевой факт: жадный алгоритм оптимален на матроиде.

## Быстрый старт

```bash
cargo run --example spanning
cargo run --example scheduling
cargo run --example linear
cargo run --example rank
cargo test
```

## Идея

Матроид — это основное множество с семейством независимых множеств, удовлетворяющим двум аксиомам.

- *Наследственность*: каждое подмножество независимого множества независимо.
- *Обмен*: если `A` и `B` независимы и $|B| > |A|$, то некоторый элемент из $B \setminus A$ можно добавить в `A`, сохранив его независимым.

На матроиде жадный алгоритм находит независимое множество максимального веса: брать элементы в порядке убывания веса, пока сохраняется независимость.
На любой другой системе независимости тот же процесс можно обмануть.

Конкретные системы в крейте:

| Система                    | Основное множество         | Независимые множества                      |
| -------------------------- | -------------------------- | ------------------------------------------ |
| `UniformMatroid` $U_{k,n}$ | `n` элементов              | подмножества размера не больше `k`         |
| `GraphicMatroid`           | индексы рёбер графа        | ациклические множества рёбер (леса)        |
| `BinaryLinearMatroid`      | строки бинарной матрицы    | линейно независимые подмножества над GF(2) |
| `SchedulingMatroid`        | индексы заданий со сроками | множества заданий, планируемых по срокам   |

Функция ранга `rank(m)` возвращает размер максимального независимого множества.
Жадный алгоритм с единичными весами возвращает базу, а все базы матроида имеют одинаковый размер, поэтому ранг определён корректно.

## Демо

| Демо         | Что показывает                                                                                        |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| `spanning`   | Краскал как жадный алгоритм на графическом матроиде: максимальное остовное дерево треугольника, вес 9 |
| `scheduling` | задания со сроками как матроид: жадный алгоритм выбирает `{A, C}` с прибылью 80                       |
| `linear`     | линейный матроид над GF(2): три вектора, жадный алгоритм выбирает `{v1, v2}` с весом 9                |
| `rank`       | ранг графического, линейного и равномерного матроидов: все равны 2                                    |

## API

| Элемент                | Что делает                                                                        |
| ---------------------- | --------------------------------------------------------------------------------- |
| типаж `Matroid`        | `n()` плюс `is_independent(&[u32]) -> bool`, оракул независимости                 |
| `greedy(m, weights)`   | независимое множество максимального веса на матроиде                              |
| `rank(m)`              | размер максимального независимого множества (жадный алгоритм с единичными весами) |
| `weight(set, weights)` | суммарный вес выбранного множества                                                |
| `UniformMatroid`       | равномерный матроид $U_{k,n}$, поля `n`, `k`                                      |
| `GraphicMatroid`       | графический матроид списка рёбер, поля `vertices`, `edges`                        |
| `BinaryLinearMatroid`  | линейный матроид над GF(2), поле `vectors`                                        |
| `SchedulingMatroid`    | матроид планирования, поле `deadlines`                                            |

## Тесты

`cargo test` запускает два интеграционных файла.
`greedy_test.rs` проверяет, что жадный алгоритм оптимален на равномерном, графическом матроиде и матроиде планирования.
`linear_rank_test.rs` проверяет независимость над GF(2), жадный алгоритм на линейном матроиде, ранги всех четырёх систем и то, что каждая база матроида имеет одинаковый размер при любых весах.
