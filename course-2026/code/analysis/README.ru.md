# analysis

Абстрактная интерпретация: абстрактные домены, переносящие функции и расширение (widening).

Домены знаков, интервалов и констант; абстрактная арифметика над ними; и переносящие функции над крошечной императивной программой.
Циклы анализируются вычислением неподвижной точки; на бесконечных доменах интервалов и констант расширение (widening) заставляет итерацию сходиться.

## Быстрый старт

```bash
cargo run -p analysis --example sign_analysis
cargo run -p analysis --example interval_analysis
cargo run -p analysis --example constant_propagation
cargo run -p analysis --example distributive_flow
cargo test -p analysis
```

## Основная идея

Программа работает на абстрактных значениях вместо конкретных.
Присваивания вычисляют выражения абстрактно; `if` сливает обе ветви с помощью объединения ⊔; цикл `while` итерирует своё тело до неподвижной точки.
Решётка знаков конечна, поэтому обычная итерация сходится; решётки интервалов и констант бесконечны, поэтому циклы итерируются с расширением (widening):

$$ w_{k+1} = w_k \nabla F(w_k) $$

Демо интервалов запускает цикл счётчика: наивная итерация бесконечно поднимается `[0,0], [0,1], [0,2], ...`, тогда как расширение отбрасывает движущуюся границу и сходится к `[0, +∞)` за два шага.
Демо констант показывает ключевую идею, что ноль, умноженный на неизвестное, всё равно ноль.

## API

| Элемент | Назначение |
| --- | --- |
| `Sign` | Пятиэлементная решётка знаков (−, 0, +, ⊥, ⊤) с `+`, `*`, `-` и `lub` |
| `Interval` | Домен интервалов с `+`, `*`, `-`, `lub` и `widen` (∇) |
| `Const` | Домен констант с `+`, `*`, `-`, `lub` и `widen` (∇) |
| `Expr`, `Stmt` | Крошечная императивная программа |
| `eval_sign`, `exec_sign` | Переносящие функции домена знаков |
| `eval_interval`, `exec_interval` | Переносящие функции домена интервалов с расширением |
| `eval_const`, `exec_const` | Переносящие функции домена констант с расширением |

## Демо

| Демо | Что показывает |
| --- | --- |
| `sign_analysis` | Цена абстракции: `+ ⊞ − = ⊤`, и слияние ветвей через объединение |
| `interval_analysis` | Цикл счётчика: расширение превращает расходящуюся итерацию в неподвижную точку |
| `constant_propagation` | Константы через арифметику, потеря точности из-за ветвлений и 0·⊤ = 0 |
| `distributive_flow` | Почему важна дистрибутивность функций потока: `f(x ⊔ y)` против `f(x) ⊔ f(y)` на монотонной и дистрибутивной функции |

## Тесты

```bash
cargo test -p analysis
```

Тесты покрывают таблицы абстрактной арифметики для всех трёх доменов, слияние ветвей, граничные случаи расширения, сходимость к неподвижной точке на циклах while и идею «ноль, умноженный на неизвестное» из распространения констант.
