# analysis

Абстрактная интерпретация: домен констант, переносящие функции и итерация до неподвижной точки.

Крошечная императивная программа анализируется на абстрактных значениях.
Домен констант отслеживает, какие переменные содержат известное целое (⊥ — недостижимо, ⊤ — «не константа»).
Присваивания вычисляют выражения абстрактно; `if` сливает обе ветви с помощью объединения ⊔; цикл `while` итерирует своё тело до неподвижной точки итерацией Клини.

## Быстрый старт

```bash
cargo run -p analysis --example constant_propagation
cargo run -p analysis --example distributive_flow
cargo test -p analysis
```

## Основная идея

Программа работает на абстрактных значениях вместо конкретных.
Присваивания вычисляют выражения абстрактно; `if` сливает обе ветви с помощью объединения ⊔; цикл `while` итерирует своё тело до неподвижной точки.
Цикл анализируется итерацией Клини от состояния на входе в цикл: после каждого прохода состояние объединяется с состоянием на входе, и итерация останавливается, когда она стабилизируется.

Так как объединение двух разных констант даёт ⊤ (а каждая операция сохраняет ⊤), итерация сходится быстро.
Демо показывает ключевую идею распространения констант: ноль, умноженный на неизвестное, всё равно ноль.

## API

| Элемент | Назначение |
| --- | --- |
| `Const` | Домен констант (⊥, известные значения, ⊤) с `+`, `*`, `-` и `lub` (⊔) |
| `Expr`, `Stmt` | Крошечная императивная программа |
| `eval_const`, `exec_const` | Переносящие функции домена констант с итерацией Клини до неподвижной точки |

## Демо

| Демо | Что показывает |
| --- | --- |
| `constant_propagation` | Константы через арифметику, потеря точности из-за ветвлений и 0·⊤ = 0 |
| `distributive_flow` | Почему важна дистрибутивность функций потока: `f(x ⊔ y)` против `f(x) ⊔ f(y)` на монотонной и дистрибутивной функции |

## Тесты

```bash
cargo test -p analysis
```

Тесты покрывают решётку и арифметику домена констант, слияние ветвей, сходимость итерации Клини на цикле while и идею «ноль, умноженный на неизвестное» из распространения констант.
