# heyting

Конечные алгебры Гейтинга и интуиционистская общезначимость.

Алгебра Гейтинга --- это дистрибутивная решётка с относительным псевдодополнением `a -> b` (слабейшее `c`, для которого `a ∧ c <= b`).
Трёхэлементная алгебра `{0, 1/2, 1}` --- простейшая небулева: её средний элемент `1/2` («ещё не построено») --- это то место, где нарушается закон исключённого третьего, что делает её стандартной контрпримерной семантикой для интуиционистской логики.

Этот крейт выходит за рамки трёхэлементного примера: он предлагает общие конечные алгебры Гейтинга, задаваемые таблицами, конструкцию нижних множеств (порядковых идеалов) из небольших частично упорядоченных множеств, булевы алгебры, крошечный язык формул, вычисляемый в любой алгебре, и исчерпывающий проверщик общезначимости по всем конечным алгебрам Гейтинга размером до 5 элементов.

## Быстрый старт

```bash
cargo run -p heyting --example values
cargo run -p heyting --example excluded_middle
cargo run -p heyting --example semantics
cargo test -p heyting
```

## Идея

Булевы алгебры моделируют классическую истинность: каждое высказывание либо истинно, либо ложно.
Алгебра Гейтинга сохраняет структуру решётки --- пересечение --- это `and`, объединение --- это `or`, псевдодополнение --- это `implication` --- но отбрасывает закон `a ∨ ¬a = 1`.
В `{0, 1/2, 1}` отрицание --- это `!a = a -> 0`, поэтому `¬(1/2) = 0` и `1/2 ∨ ¬(1/2) = 1/2 ≠ 1`: закон исключённого третьего и исключение двойного отрицания не являются тавтологиями.
Формулы, общезначимые в *каждой* алгебре Гейтинга, --- это в точности теоремы интуиционистской логики, поэтому конечные алгебры Гейтинга точно фиксируют то, что конструктивная математика отказывается утверждать.

Ключевая конструкция, связывающая частично упорядоченные множества с интуиционистской семантикой: нижние множества (порядковые идеалы) частично упорядоченного множества образуют алгебру Гейтинга, где `A -> B` --- это наибольший идеал `I` такой, что `I ∩ A ⊆ B`.
Каждая конечная алгебра Гейтинга с точностью до изоморфизма является подалгеброй такой алгебры нижних множеств (двойственность Биркгофа).

## Демо

| Демо | Что показывает |
|------|---------------|
| `values` | Таблицы истинности пересечения, объединения, импликации и отрицания трёхэлементной алгебры, а также две формулы, проверенные по всем оценкам: тавтология `p -> (q -> p)` и закон Пирса, который не выполняется |
| `excluded_middle` | Где выполняются `p ∨ ¬p` и `¬¬p -> p`, а где нет (при `1/2`) |
| `semantics` | Алгебра нижних множеств 3-элементного частично упорядоченного множества, закон исключённого третьего и исключение двойного отрицания, вычисленные по всем оценкам, и проверка общезначимости пяти формул по полному перечислению малых алгебр Гейтинга |

## API

| Элемент | Что делает |
|------|--------------|
| `Value` | Три элемента `Bot`, `Mid`, `Top`, упорядоченные как `0 < 1/2 < 1` |
| `Value::meet/join/implies`, `!a` | Операции трёхэлементной алгебры |
| `Algebra` | Общая конечная алгебра Гейтинга: элементы `0..n` с таблицами пересечения/объединения/импликации, нижний элемент, верхний элемент и метки элементов |
| `Algebra::from_meet_join` | Построение алгебры из таблиц решётки; импликация выводится из сопряжения Гейтинга |
| `chain_three()` | Канонический пример как табличная алгебра: алгебра нижних множеств 2-элементной цепи |
| `bool_algebra(n)` | Булева алгебра всех подмножеств `n`-элементного множества (2^n элементов) |
| `Poset::from_relations` / `from_less` | Небольшое частично упорядоченное множество на `0..n` |
| `Poset::downset_algebra` | Алгебра Гейтинга его нижних множеств (порядковых идеалов) |
| `Formula` | Крошечный тип пропозициональной формулы: атомы, `∧`, `∨`, `->`, `¬`, `⊤`, `⊥` |
| `Formula::eval` | Вычисление формулы в алгебре при оценке |
| `all_valuations` | Перечисление всех оценок `n` атомов в алгебре из `size` элементов |
| `valid_in` | Является ли формула `⊤` при каждой оценке в одной алгебре? |
| `valid` | Общезначима ли формула в каждой конечной алгебре Гейтинга размером до 5 элементов? |
| `all_finite_heyting_algebras` | Точное перечисление, используемое `valid` (кэшируется) |

```rust
use heyting::{Formula, valid, chain_three};

// Excluded middle fails at 1/2.
use std::ops::Not;
assert_eq!(heyting::Value::Mid.join(!heyting::Value::Mid), heyting::Value::Mid);

// The same failure, in the table algebra and via the validity checker.
let p = Formula::atom(0);
assert!(!valid(&p.clone().or(!p)));       // p ∨ ¬p is not intuitionistically valid
assert!(valid(&Formula::atom(0).implies(Formula::atom(0)))); // p -> p is
assert_eq!(chain_three().size(), 3);
```

## Перечисление общезначимости

`valid` проверяет формулу на каждой алгебре, порождённой `all_finite_heyting_algebras`, которая строится как:

1. каждый частичный порядок на `0..n` для `n <= 4` (243 частично упорядоченных множества),
2. алгебра нижних множеств каждого частично упорядоченного множества (не более 16 элементов),
3. каждая подалгебра каждой алгебры нижних множеств (подмножества, замкнутые относительно `∧`, `∨`, `->`), с дедупликацией с точностью до изоморфизма.

Каждая конечная алгебра Гейтинга размером не более 5 элементов присутствует (по двойственности Биркгофа: алгебра Гейтинга размера `k` имеет не более `k-1` неразложимых по объединению элементов), поэтому проверка исчерпывающая вплоть до размера 5; коллекция также содержит 7 алгебр размера 6 и более крупные вплоть до 16-элементной булевой алгебры.
Полный список кэшируется после первого вызова.
