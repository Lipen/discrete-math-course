# heyting

Конечные алгебры Гейтинга и интуиционистская общезначимость.

Алгебра Гейтинга — это дистрибутивная решётка с относительным псевдодополнением: операцией $\to$, где $a \to b$ — слабейший $c$, удовлетворяющий

$$a \land c \le b.$$

Трёхэлементная алгебра $\{0, 1/2, 1\}$ — простейшая небулева.
Её средний элемент $1/2$ («ещё не построено») — то место, где нарушается закон исключённого третьего, что делает алгебру стандартной контрпримерной семантикой для интуиционистской логики.

Крейт содержит:

- `Value` — трёхэлементная алгебра в виде простого перечисления, с `meet`/`join`/`implies` и отрицанием `!`
- `Algebra` — произвольная конечная алгебра Гейтинга, заданная таблицами meet/join/implies: строится из таблиц решётки или как булева алгебра
- `Poset` и нижние множества — конструкция порядковых идеалов, связывающая частичные порядки с интуиционистской семантикой
- `Formula` — крошечный язык пропозициональных формул, вычисляемый в любой алгебре
- `valid` — исчерпывающая проверка общезначимости по всем конечным алгебрам Гейтинга до 5 элементов

## Быстрый старт

```bash
cargo run --example values
cargo run --example excluded_middle
cargo run --example semantics
cargo test
```

## Идея

Булевы алгебры моделируют классическую истинность: каждое высказывание либо истинно, либо ложно.
Алгебра Гейтинга сохраняет структуру решётки и отбрасывает закон $a \lor \lnot a = 1$:

- пересечение $\land$ играет роль `and`,
- объединение $\lor$ — роль `or`,
- относительное псевдодополнение $\to$ — роль импликации.

В $\{0, 1/2, 1\}$ отрицание — это $\lnot a = a \to 0$, поэтому $\lnot(1/2) = 0$ и

$$1/2 \lor \lnot(1/2) = 1/2 \ne 1.$$
Закон исключённого третьего и исключение двойного отрицания там не тавтологии.
Формулы, общезначимые в *каждой* алгебре Гейтинга, — это в точности теоремы интуиционистской логики, поэтому конечные алгебры Гейтинга точно фиксируют то, что конструктивная математика отказывается утверждать.

Ключевая конструкция, связывающая частичные порядки с интуиционистской семантикой: нижние множества (порядковые идеалы) частично упорядоченного множества образуют алгебру Гейтинга, где $A \to B$ — наибольший идеал $I$ с $I \cap A \subseteq B$.
Каждая конечная алгебра Гейтинга с точностью до изоморфизма является подалгеброй такой алгебры нижних множеств (двойственность Биркгофа).

## API

| Элемент                               | Что делает                                                                                                                      |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `Value`                               | Три элемента `Bot`, `Mid`, `Top`, упорядоченные как $0 < 1/2 < 1$                                                               |
| `Value::meet`/`join`/`implies`, `!a`  | Операции трёхэлементной алгебры                                                                                                 |
| `Algebra`                             | Общая конечная алгебра Гейтинга: элементы `0..n` с таблицами meet/join/implies, нижним и верхним элементами и метками элементов |
| `Algebra::from_meet_join`             | Построение алгебры из таблиц решётки, импликация выводится из сопряжения Гейтинга                                               |
| `chain_three()`                       | Канонический пример как табличная алгебра: алгебра нижних множеств 2-элементной цепи                                            |
| `bool_algebra(n)`                     | Булева алгебра всех подмножеств `n`-элементного множества ($2^n$ элементов)                                                     |
| `Poset::from_relations` / `from_less` | Небольшое частично упорядоченное множество на `0..n`                                                                            |
| `Poset::downset_algebra`              | Алгебра Гейтинга его нижних множеств (порядковых идеалов)                                                                       |
| `Formula`                             | Крошечный тип пропозициональной формулы: атомы, $\land$, $\lor$, $\to$, $\lnot$, $\top$, $\bot$                                 |
| `Formula::eval`                       | Вычисление формулы в алгебре при оценке                                                                                         |
| `all_valuations`                      | Перечисление всех оценок `n` атомов в алгебре из `size` элементов                                                               |
| `valid_in`                            | Является ли формула $\top$ при каждой оценке в одной алгебре?                                                                   |
| `valid`                               | Общезначима ли формула в каждой конечной алгебре Гейтинга размером до 5 элементов?                                              |
| `all_finite_heyting_algebras`         | Точное перечисление, используемое `valid` (кэшируется)                                                                          |

## Демо

| Демо              | Что показывает                                                                                                                                                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `values`          | Таблицы истинности пересечения, объединения, импликации и отрицания трёхэлементной алгебры, плюс две формулы по всем оценкам: тавтология `p -> (q -> p)` и закон Пирса, который не выполняется                                          |
| `excluded_middle` | Где выполняются `p ∨ ¬p` и `¬¬p -> p`, а где нет (при `1/2`)                                                                                                                                                                            |
| `semantics`       | Алгебра нижних множеств 3-элементного частично упорядоченного множества, закон исключённого третьего и исключение двойного отрицания по всем оценкам, проверка общезначимости пяти формул по полному перечислению малых алгебр Гейтинга |

`values` печатает таблицы и помечает закон Пирса как нетавтологию.
`semantics` завершается вердиктами по пяти формулам: две общезначимы, три классических закона отвергнуты.

## Перечисление общезначимости

`valid` проверяет формулу на каждой алгебре, порождённой `all_finite_heyting_algebras`, и строится в три шага:

1. каждый частичный порядок на `0..n` для `n <= 4` (243 частично упорядоченных множества),
2. алгебра нижних множеств каждого такого множества (не более 16 элементов),
3. каждая подалгебра каждой алгебры нижних множеств (подмножества, замкнутые относительно пересечения, объединения и импликации), с дедупликацией с точностью до изоморфизма.

Каждая конечная алгебра Гейтинга размером не более 5 элементов присутствует: по двойственности Биркгофа алгебра размера $k$ имеет не более $k - 1$ неразложимых по объединению элементов, поэтому проверка исчерпывающая вплоть до размера 5.
Коллекция также содержит 4 алгебры размера 6 и более крупные вплоть до 16-элементной булевой алгебры.
Полный список кэшируется после первого вызова.
