# sat

Небольшой SAT-решатель на основе алгоритма DPLL.

Решатель реализует процедуру Дэвиса–Патнема–Логемана–Лавленда: единичное распространение, устранение чистых литералов и хронологический возврат.
Литерал — целое число: `v` означает, что переменная `v` истинна, `-v` — что она ложна.
Формула — конъюнкция дизъюнктов, каждый дизъюнкт — дизъюнкция литералов.

Это DPLL, а не CDCL: изучение дизъюнктов и нехронологический возврат исключены.

## Быстрый старт

```bash
cargo run --example dpll_demo
cargo run --example pigeonhole
cargo run --example random_3sat
cargo test
```

## Идея

DPLL выбирает значение переменной, распространяет принуждённые присваивания, устраняет чистые литералы и выполняет возврат при конфликте.
Дизъюнкт единичен, когда ровно один его литерал не получил значения, а остальные ложны: этот литерал принуждён.
Переменная чиста, когда в невыполненных дизъюнктах она встречается лишь в одной полярности, и выполняющее значение можно присвоить сразу.
При конфликте поиск отменяет последнее решение.
Когда каждое решение испробовано в обе стороны, формула невыполнима.

Демо с трассировкой запускает решатель на формуле

$$ F = (x_1 \lor x_2 \lor x_3) \land (\neg x_1 \lor x_2) \land (x_2 \lor \neg x_3) \land (\neg x_2 \lor x_3) \land (\neg x_2 \lor \neg x_3) $$

которая невыполнима: DPLL исчерпывает каждую ветвь и возвращает `None`.

## Демо

| Демо          | Что показывает                                                                                                              |
| ---           | ---                                                                                                                         |
| `dpll_demo`   | Невыполнимая формула выше с пошаговой трассировкой, затем выполнимая формула, решаемая устранением чистых литералов         |
| `pigeonhole`  | Формулы принципа Дирихле $PHP(n, n - 1)$ для $n = 2..5$, все невыполнимы: классический трудный случай для DPLL              |
| `random_3sat` | Фазовый переход случайного 3-SAT около отношения числа дизъюнктов к числу переменных $4.3$                                  |

`dpll_demo` печатает каждый принуждённый литерал, каждую чистую переменную, каждое решение и каждый возврат: дерево поиска читается прямо из вывода.
`pigeonhole` кодирует расселение $n$ голубей по $n - 1$ клеткам: каждому голубю нужна клетка, и в одной клетке не могут сидеть два голубя.
`random_3sat` решает по двадцать случайных экземпляров для каждого отношения от 1 до 6 и печатает, сколько из них выполнимо.

## API

| Элемент                                               | Модуль | Назначение                                                          |
| ---                                                   | ---    | ---                                                                 |
| `Lit`, `Clause`                                       | `cnf`  | Псевдонимы типов литерала и дизъюнкта                               |
| `pos`, `neg`                                          | `cnf`  | Конструкторы положительных и отрицательных литералов                |
| `var_of`, `lit_idx`, `is_pos`                         | `cnf`  | Аксессоры литерала                                                  |
| `clause_satisfied`, `unit_of`, `clause_has_unassigned` | `cnf` | Проверки дизъюнкта при частичном присваивании                       |
| `Cnf`                                                 | `cnf`  | Формула с `num_vars` и `clauses`, плюс `new` и `random_3sat`        |
| `format_lit`, `format_clause`, `format_cnf`           | `cnf`  | Читаемая запись литералов, дизъюнктов и формул                      |
| `solve`                                               | `dpll` | Выполняющее присваивание или `None` для невыполнимой формулы        |
| `solve_traced`                                        | `dpll` | `solve` с пошаговой трассировкой в stdout                           |

## Тесты

Решатель проверяется на единичных дизъюнктах, чистых литералах, тавтологиях, непосредственных конфликтах и принципе Дирихле.
Каждое возвращённое присваивание сверяется со всеми дизъюнктами.
Рандомизированные тесты сравнивают DPLL с полным перебором всех присваиваний на небольших формулах.
