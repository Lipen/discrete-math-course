# sat

Небольшой SAT-решатель на основе DPLL --- учебный крейт для SAT и NP-полноты.

Реализует алгоритм Дэвиса–Патнема–Логемана–Лавленда: единичное распространение, устранение чистых литералов и хронологический возврат (бэктрекинг).
Литералы --- это целые числа (`v` = переменная истинна, `-v` = переменная ложна); формула --- это конъюнкция дизъюнктов.

Это DPLL, а не CDCL: изучение дизъюнктов и нехронологический возврат намеренно исключены из крейта.

## Быстрый старт

```bash
cargo run -p sat --example dpll_demo
cargo run -p sat --example pigeonhole
cargo run -p sat --example random_3sat
cargo test -p sat
```

## Идея

DPLL выбирает значение переменной, распространяет единичные дизъюнкты (дизъюнкты ровно с одним неприсвоенным литералом, остальные ложны), устраняет чистые литералы (переменные, встречающиеся только в одной полярности) и выполняет возврат (бэктрекинг) при обнаружении конфликта.

Пример `dpll_demo` запускает решатель с пошаговой трассировкой на разобранном примере:

$$ F = (x_1 \lor x_2 \lor x_3) \land (\neg x_1 \lor x_2) \land (x_2 \lor \neg x_3) \land (\neg x_2 \lor x_3) \land (\neg x_2 \lor \neg x_3) $$

который невыполним --- DPLL исчерпывает каждую ветвь и сообщает `None`.

## API

| Элемент | Модуль | Назначение |
| --- | --- | --- |
| `Lit`, `Clause` | `cnf` | Псевдонимы типов литерала и дизъюнкта |
| `pos`, `neg` | `cnf` | Создание положительных/отрицательных литералов |
| `var_of`, `lit_idx`, `is_pos` | `cnf` | Аксессоры литерала |
| `clause_satisfied`, `unit_of`, `clause_has_unassigned` | `cnf` | Вспомогательные функции уровня дизъюнкта |
| `Cnf` | `cnf` | КНФ-формула: `num_vars`, `clauses`, `new`, `random_3sat` |
| `format_lit`, `format_clause`, `format_cnf` | `cnf` | Вспомогательные функции вывода |
| `solve` | `dpll` | Найти модель или вернуть `None`, если формула невыполнима |
| `solve_traced` | `dpll` | Решение с пошаговой трассировкой, выводимой в stdout |

## Демо

| Демо | Показывает |
| --- | --- |
| `dpll_demo` | Невыполнимая формула (с трассировкой), а также выполнимая с устранением чистого литерала |
| `pigeonhole` | Формулы принципа Дирихле PHP(n, n-1) невыполнимы (n=2..5) --- классический трудный случай для SAT-решателей |
| `random_3sat` | Фазовый переход: случайный 3-SAT переходит из выполнимого в невыполнимый при отношении дизъюнктов к переменным ≈ 4.3 |

## Тесты

```bash
cargo test -p sat
```

Решатель проверяется на выполнимых и невыполнимых формулах (единичные дизъюнкты, чистые литералы, тавтологии, принцип Дирихле).
Каждая возвращённая модель проверяется на всех дизъюнктах.
Рандомизированные тесты сравнивают DPLL с полным перебором на небольших формулах.
