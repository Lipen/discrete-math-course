# model-checking

Набор инструментов для проверки моделей: раскраска состояний CTL над структурами Крипке.

Структура Крипке `(S, R, L)` — это ориентированный граф состояний с атомарными пометками.
Проверка CTL работает путём *раскраски состояний*: снизу вверх по подформулам вычисляется множество состояний, в которых выполняется каждая подформула.
Этот крейт покрывает основу алгоритма — атомы, булевы связки и одноместные модальности `EX` / `AX`.
Модальности через неподвижные точки (`EF`, `EG`, `EU` и их `A`-дуалы), которые вычисляют достижимость, живость и безопасность, — тема отдельного проекта.

## Быстрый старт

```bash
cargo test
```

## Идея

Проверка моделей отвечает на вопрос верификации: удовлетворяет ли каждый (или некоторый) прогон системы временному свойству?
Свойства CTL вычисляются на графе состояний, а не на отдельных прогонах.
Одноместные операторы смотрят на один переход вперёд:

- `EX φ` — *некоторое* состояние-преемник удовлетворяет `φ`.
- `AX φ` — *каждое* состояние-преемник удовлетворяет `φ` (вакуумно истинно в тупике).

Проверяющий помечает каждое состояние подформулами, истинными в нём, идя снизу вверх:

| Оператор           | Правило раскраски                                        |
| ------------------ | -------------------------------------------------------- |
| атом `p`           | состояния, у которых `atoms` содержит `p`                |
| `¬φ`               | дополнение пометки `φ`                                   |
| `φ ∧ ψ` / `φ ∨ ψ`  | поточечное «и» / «или» двух пометок                      |
| `EX φ`             | состояния с *некоторым* преемником в пометке `φ`         |
| `AX φ`             | состояния со *всеми* преемниками в пометке `φ`           |

Шаги `EX` / `AX` — это в точности операторы прообраза `Kripke::pre_exists` / `Kripke::pre_forall`.

## API

| Элемент                                           | Что делает                                                                        |
| ------------------------------------------------- | --------------------------------------------------------------------------------- |
| `Kripke::new(successors, atoms)`                  | Структура Крипке с `n` состояниями, `successors[s]` и `atoms[s]` для каждого      |
| `Kripke::pre_exists(set)` / `pre_forall(set)`     | Прообраз за один переход (шаг `EX` / `AX`)                                        |
| `ctl::Formula`                                    | Формулы CTL: `Atom`, `Not`, `And`, `Or`, `Ex`, `Ax`                               |
| `check(&Kripke, &Formula) -> Vec<bool>`           | Проверка через раскраску, по биту на состояние                                    |

```rust
use model_checking::{check, Formula, Kripke};

// Светофор: зелёный -> жёлтый -> красный -> зелёный.
let m = Kripke::new(
    vec![vec![1], vec![2], vec![0]],
    vec![vec![0], vec![1], vec![2]], // атомы: 0 = зелёный, 1 = жёлтый, 2 = красный
);

// EX red: некоторый преемник красный -- истинно из жёлтого.
let next_red = Formula::Ex(Box::new(Formula::Atom(2)));
assert_eq!(check(&m, &next_red), vec![false, true, false]);

// AX green: каждый преемник зелёный -- истинно только из красного.
let next_green = Formula::Ax(Box::new(Formula::Atom(0)));
assert_eq!(check(&m, &next_green), vec![false, false, true]);
```

## Тесты

Модульные тесты покрывают операторы прообраза в тупиковых состояниях и петлях, а также проверку через раскраску на цикле светофора для атомов, булевых связок, `EX` и `AX`.
