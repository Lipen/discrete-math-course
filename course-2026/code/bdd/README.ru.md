# bdd

Редуцированные упорядоченные бинарные диаграммы решений (ROBDD) с дополняющими рёбрами.

Канонический менеджер BDD: таблица узлов с правилом уникальности узлов, редукция (отбрасывание избыточных узлов) и дополняющие рёбра, так что отрицание ничего не стоит.
Фундаментальная операция --- `ite`; `and`, `or` и `xor` --- её частные случаи.

Такие операции, как проверка выполнимости, тавтологии и эквивалентности, становятся тривиальными, как только построен канонический BDD --- каждая функция имеет ровно одно представление.

## Быстрый старт

```bash
cargo run -p bdd --example bdd_demo
cargo run -p bdd --example var_order
cargo run -p bdd --example expr_demo
cargo test -p bdd
```

## Как это работает

BDD представляет булеву функцию через разложение Шеннона: узел `(v, lo, hi)` означает «если переменная `v`, то `hi`, иначе `lo`».
Редукция и совместное использование узлов делают представление каноническим: при фиксированном порядке переменных каждая функция имеет ровно один ROBDD.
Дополняющие рёбра хранят отрицание как флаг на ребре, поэтому `not` никогда не строит новый узел, и функции с обилием дополнений остаются компактными.

## API

| Элемент | Назначение |
| --- | --- |
| `Bdd::new` | Создать свежий менеджер с узлом-константой |
| `Bdd::var` | BDD для одной переменной `x_i` |
| `Bdd::not`, `and`, `or`, `xor` | Булевы операции, построенные на `ite` |
| `Bdd::ite` | Фундаментальный тернарный оператор `ite(f, g, h)` |
| `Bdd::eval` | Вычислить функцию при назначении переменных |
| `Bdd::sat_count` | Подсчитать, сколько назначений удовлетворяют функции |
| `Bdd::restrict` | Зафиксировать переменную значением |
| `Bdd::is_tautology` | Проверить, всегда ли функция истинна |
| `Bdd::is_satisfiable` | Проверить, есть ли у функции хотя бы одна модель |
| `Bdd::size` | Число узлов в менеджере |
| `Expr` | AST булевых выражений (`Var`, `Not`, `And`, `Or`, `Xor`, `Implies`) |
| `Expr::to_bdd` | Построить BDD для выражения |

## Демо

| Демо | Что показывает |
| --- | --- |
| `bdd_demo` | Построение ROBDD для `x XOR y`, вычисление, `sat_count`, `restrict` |
| `var_order` | Как порядок переменных влияет на размер BDD |
| `expr_demo` | Построение BDD из выражений, эквивалентность, проверка тавтологии |

## Тесты

```bash
cargo test -p bdd
```

Модульные тесты покрывают булевы операции против эталонных таблиц истинности, правила уникальности узлов и редукции, `sat_count` на нескольких функциях, `restrict` с дополняющими рёбрами и без них, базовые случаи `ite`, а также преобразование выражения в BDD, включая обнаружение тавтологии.
