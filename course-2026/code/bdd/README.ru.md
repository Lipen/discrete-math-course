# bdd

Редуцированные упорядоченные бинарные диаграммы решений (ROBDD) с дополняющими рёбрами.

При фиксированном порядке переменных у каждой булевой функции ровно один ROBDD, поэтому проверки выполнимости, тавтологии и эквивалентности сводятся к сравнению рёбер.
Менеджер строит каждую поддиаграмму один раз и разделяет её, а отрицание ездит на рёбрах вместо новых узлов.

## Быстрый старт

```bash
cargo run --example bdd_demo
cargo run --example var_order
cargo run --example expr_demo
cargo run --example visualize
cargo test
```

## Как это устроено

BDD представляет булеву функцию через разложение Шеннона:

$$f \;=\; (\lnot v \land f|_{v=0}) \;\lor\; (v \land f|_{v=1})$$

Узел `(v, lo, hi)` хранит одно такое разветвление: идите в `lo`, когда `v` ложна, и в `hi`, когда `v` истинна.
Фундаментальная операция — `ite(f, g, h)`, а `and`, `or` и `xor` — её частные случаи.
Мемоизация строит каждый подрезультат один раз.
Редукция и совместное использование узлов делают представление каноническим: узел с совпадающими `lo` и `hi` отбрасывается, а равные подграфы сливаются в один узел.
Дополняющие рёбра хранят отрицание как флаг на ребре, поэтому `not` никогда не строит новый узел, и функции с обилием дополнений остаются компактными.

## Демо

| Демо        | Что показывает                                                                       |
| ----------- | ------------------------------------------------------------------------------------ |
| `bdd_demo`  | Построение ROBDD для `x XOR y`, вычисление, `sat_count`, `restrict`                  |
| `var_order` | Как порядок переменных влияет на размер BDD                                          |
| `expr_demo` | Построение BDD из выражений, эквивалентность, проверка тавтологии                    |
| `visualize` | Рендер в DOT, текстовый дамп дерева, форма без дополняющих рёбер                     |

`var_order` строит одну и ту же функцию при двух порядках индексов и печатает числа узлов.
`visualize` пишет DOT-файл во временную папку и печатает абсолютный путь.

## API

| Элемент                                          | Назначение                                                               |
| ------------------------------------------------ | ------------------------------------------------------------------------ |
| `Bdd::new`                                       | Создать свежий менеджер с узлом-константой                               |
| `Bdd::var`                                       | BDD для одной переменной `x_i`                                           |
| `Bdd::not`, `and`, `or`, `xor`                   | Булевы операции, построенные на `ite`                                    |
| `Bdd::ite`                                       | Фундаментальный тернарный оператор `ite(f, g, h)`                        |
| `Bdd::eval`                                      | Вычислить функцию при назначении переменных                              |
| `Bdd::sat_count`                                 | Подсчитать, сколько назначений удовлетворяют функции                     |
| `Bdd::restrict`                                  | Зафиксировать переменную значением                                       |
| `Bdd::is_tautology`                              | Проверить, всегда ли функция истинна                                     |
| `Bdd::is_satisfiable`                            | Проверить, есть ли у функции хотя бы одна модель                         |
| `Bdd::size`                                      | Число узлов в менеджере                                                  |
| `Bdd::to_dot`                                    | Отрисовать диаграмму строкой Graphviz DOT                                |
| `Bdd::to_tree_string`                            | Выдать диаграмму текстовым деревом с пометками совместного использования |
| `Bdd::to_plain`, `PlainBdd`, `PlainNode`         | Форма диаграммы без дополняющих рёбер                                    |
| `Edge`, `TRUE` / `FALSE`                         | Индекс узла плюс флаг дополнения в бите 0, `TRUE` = 0, `FALSE` = 1       |
| `Expr`                                           | AST булевых выражений (`Var`, `Not`, `And`, `Or`, `Xor`, `Implies`)      |
| `Expr::to_bdd`                                   | Построить BDD для выражения                                              |

## Тесты

- булевы операции против эталонных таблиц истинности
- правила уникальности узлов и редукции
- `sat_count` на нескольких функциях
- `restrict` с дополняющими рёбрами и без них
- базовые случаи `ite`
- преобразование выражения в BDD, включая обнаружение тавтологии
