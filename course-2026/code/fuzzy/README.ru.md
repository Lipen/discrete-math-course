# fuzzy

Нечёткие множества, нечёткие числа и нечёткие отношения.

Нечёткое множество заменяет чёткую характеристическую функцию $\chi\colon U \to \{0, 1\}$ функцией принадлежности $\mu\colon U \to [0, 1]$: элемент принадлежит множеству *в некоторой степени*.
Крейт моделирует стандартные формы (треугольную, трапециевидную и любую ломаную) как кусочно-линейные функции, реализует операции Заде (объединение `max`, пересечение `min`, дополнение `1 - mu`), три классических семейства t-норм/t-конорм, нечёткие числа с их α-срезами и нечёткие отношения с max-min-композицией.

## Быстрый старт

```bash
cargo run --example operations
cargo run --example fuzzy_numbers
cargo run --example relations
cargo test
```

## Идея

Принадлежность — это степень, а не переключатель.
Человек ростом 175 см «высокий» в степени 0.5 и «не высокий» в степени 0.5 одновременно, поэтому закон исключённого третьего нарушается: $\mu(A \cup \lnot A)(x) = \max(\mu, 1 - \mu) < 1$ для любого промежуточного $\mu$.
Выбор t-нормы — это выбор семантики «и»: `min` идемпотентна, произведение осторожно (два эксперта по 0.7 дают 0.49), а Лукасевич восстанавливает закон противоречия ценой идемпотентности.

α-срезы вновь связывают нечёткий мир с чётким: срез $\{x : \mu(x) \ge \alpha\}$ — это обычное множество, а вся функция принадлежности восстанавливается как $\mu(x) = \sup\{a : x \in A_a\}$ (теорема о декомпозиции).

## API

| Элемент                                      | Что делает                                                                                             |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| `FuzzySet`                                   | Нечёткое множество как кусочно-линейная функция принадлежности: отсортированные точки излома `(x, mu)` |
| `membership` / `height` / `support` / `core` | Степень в точке, максимальная степень, положительная область, область `mu = 1`                         |
| `alpha_cut`                                  | $\{x : \mu(x) \ge \alpha\}$ как интервалы: `alpha_cut(0)` охватывает множество, `alpha_cut(1)` — ядро  |
| `decompose_at`                               | Теорема о декомпозиции: $\mu(x) = \sup\{a : x \in A_a\}$                                               |
| `union` / `intersection` / `complement`      | Операции Заде `max`, `min`, `1 - mu` (точные на кусочно-линейных множествах)                           |
| `TNorm`                                      | `Zadeh`, `Product`, `Lukasiewicz`, каждая с `norm` (AND) и `conorm` (OR)                               |
| `Triangular` / `Trapezoidal`                 | Нечёткие числа: принадлежность, α-срезы, покомпонентные add/sub/mul                                    |
| `FuzzyRelation`                              | Нечёткое отношение как матрица, с `max_min_compose` и `max_product_compose`                            |

## Демо

| Демо            | Что показывает                                                                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `operations`    | Объединение, пересечение и дополнение на «высокий» против «средний», законы Де Моргана, нарушение закона исключённого третьего и три t-нормы на `a = 0.6, b = 0.7` |
| `fuzzy_numbers` | Принадлежность треугольного числа, α-срезы, арифметика и восстановление из срезов                                                                                  |
| `relations`     | «x близок к y» на четырёх городах, плюс max-min- и max-product-композиция                                                                                          |

`operations` показывает объединение, пересечение и дополнение Заде как точные кусочно-линейные множества и сравнивает три семейства t-норм на одной паре степеней.
`fuzzy_numbers` восстанавливает значение принадлежности из α-срезов, демонстрируя теорему о декомпозиции.
`relations` компонует отношение близости с самим собой: города 1 и 4 непосредственно не близки, но становятся близкими через промежуточный город.

## Тесты

Юнит-тесты лежат рядом с каждым модулем.
`set.rs` покрывает срезы, законы Де Моргана и нарушение закона исключённого третьего, `number.rs` — формы и их арифметику, `relation.rs` — обе композиции.
