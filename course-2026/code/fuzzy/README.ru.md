# fuzzy

Нечёткие множества, нечёткие числа, нечёткие отношения и вывод Мамдани.

Нечёткое множество заменяет чёткое `chi: U -> {0, 1}` функцией принадлежности `mu: U -> [0, 1]`: элемент принадлежит множеству *в некоторой степени*.
Крейт моделирует стандартные формы (треугольную, трапециевидную и любую ломаную) как кусочно-линейные функции, реализует операции Заде (объединение `max`, пересечение `min`, дополнение `1 - mu`), три классических семейства t-норм/t-конорм, нечёткие числа с их α-срезами, нечёткие отношения с max-min-композицией и контроллер Мамдани, который превращает чёткие входы в чёткий выход.

## Быстрый старт

```bash
cargo run -p fuzzy --example operations
cargo run -p fuzzy --example fuzzy_numbers
cargo run -p fuzzy --example relations
cargo run -p fuzzy --example controller
cargo test -p fuzzy
```

## Идея

Принадлежность --- это степень, а не переключатель.
Человек ростом 175 см «высокий» в степени 0.5 и «не высокий» в степени 0.5 одновременно, поэтому закон исключённого третьего нарушается: `mu(A ∪ ¬A)(x) = max(mu, 1 - mu) < 1` для любого промежуточного `mu`.
Выбор t-нормы --- это выбор семантики «и»: `min` идемпотентна, произведение осторожно (два эксперта по 0.7 дают 0.49), а Лукасевич восстанавливает закон противоречия ценой идемпотентности.

α-срезы вновь связывают нечёткий мир с чётким: срез `{x : mu(x) >= a}` --- это обычное множество, а вся функция принадлежности восстанавливается как `mu(x) = sup {a : x in A_a}` (теорема о декомпозиции).
Контроллер Мамдани затем фазифицирует чёткие входы, пропорционально активирует правила, агрегирует срезанные консеквенты и дефазифицирует результат в одно число с помощью центроида, среднего максимума или биссектрисы.

## API

| Элемент | Что делает |
|------|--------------|
| `FuzzySet` | Нечёткое множество как кусочно-линейная функция принадлежности: отсортированные точки излома `(x, mu)` |
| `membership` / `height` / `support` / `core` | Степень в точке, максимальная степень, положительная область, область `mu = 1` |
| `alpha_cut` | `{x : mu(x) >= alpha}` как интервалы; `alpha_cut(0)` охватывает множество, `alpha_cut(1)` --- ядро |
| `decompose_at` | Теорема о декомпозиции: `sup {a : x in A_a}` |
| `union` / `intersection` / `complement` | Операции Заде `max`, `min`, `1 - mu` (точные на кусочно-линейных множествах) |
| `clip` | `min(mu, level)`: срезать консеквент при силе активации |
| `TNorm` | `Zadeh`, `Product`, `Lukasiewicz`, каждая с `norm` (AND) и `conorm` (OR) |
| `Triangular` / `Trapezoidal` | Нечёткие числа: принадлежность, α-срезы, покомпонентные add/sub/mul |
| `FuzzyRelation` | Нечёткое отношение как матрица; `max_min_compose` и `max_product_compose` |
| `Mamdani` | База правил плюс лингвистические переменные: `fuzzify`, `firing_strength`, `aggregate`, `infer` |
| `defuzzify` / `centroid` / `mean_of_max` / `bisector` | Три метода дефазификации |

## Демо

| Демо | Что показывает |
|------|---------------|
| `operations` | Объединение/пересечение/дополнение на «высокий» против «средний», законы Де Моргана, нарушение закона исключённого третьего и три t-нормы на `a = 0.6, b = 0.7` |
| `fuzzy_numbers` | Принадлежность ТНЧ, α-срезы, арифметика и восстановление из срезов |
| `relations` | «x близок к y» на четырёх городах, плюс max-min- и max-product-композиция |
| `controller` | Кондиционер Мамдани: фазификация, силы активации, агрегация, дефазификация и плавная развёртка |
