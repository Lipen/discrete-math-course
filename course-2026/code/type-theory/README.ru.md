# type-theory

Простое типизированное λ-исчисление (λ→).

Типы (базовый + функция, и контексты), три правила типизации var/app/abs как
*проверка* над термами с аннотациями Чёрча, *вывод* наиболее общего типа
бестипового терма унификацией с метапеременными и сохранение типа при редукции:
типизированный терм β-редуцируется, сохраняя свой тип. Самоприменение `λx. x x`
отвергается --- ему понадобилось бы `σ = σ -> τ`.

## Быстрый старт

```bash
cargo run -p type-theory --example typed_terms
cargo run -p type-theory --example inference
cargo run -p type-theory --example subject_reduction
cargo test -p type-theory
```

## Система типов

Тип --- это базовый тип (`Nat`, `Bool`, ...) или функциональный тип `σ -> τ`.
Три правила типизации --- это вся система:

$$
   \frac{}{(x:\sigma)\in\Gamma}\;\textbf{var} \\[1em]
   \frac{\Gamma\vdash M:\sigma\to\tau\quad\Gamma\vdash N:\sigma}{\Gamma\vdash MN:\tau}\;\textbf{app} \\[1em]
   \frac{\Gamma,x:\sigma\vdash M:\tau}{\Gamma\vdash\lambda x:\sigma.\;M:\sigma\to\tau}\;\textbf{abs}
$$

Проверка аннотированного терма --- это короткий обход по этим правилам; вывод
типа бестипового терма присваивает каждому связывателю свежие метапеременные и унифицирует.
Поскольку `x` в `λx. x x` должен был бы быть одновременно аргументом и функцией,
вывод требует `σ = σ -> τ`, что отвергается проверкой вхождения (occurs check).

Тождество `λx:A. x` типизируется как `A -> A` одним шагом `var` под одним шагом `abs`:

$$
\frac{
   \frac{}{(x:A)\in\Gamma}\;\textbf{var}
}{
   \vdash \lambda x:A.\;x : A \to A
}\;\textbf{abs}
$$

## Модули

| Модуль | Содержимое |
|--------|----------|
| `ty` | `Type` (Base, Arrow, Var), `Context` (переменная -> предположения о типе), отображение |
| `term` | Бестиповый `Term` (Var, Abs, App), подстановка без захвата, β-редукция |
| `checker` | `STerm` с аннотациями Чёрча, правила var/app/abs в `STerm::check`, стирание, `TypeError`, β-шаги сохранения типа |
| `infer` | Вывод на основе унификации (алгоритм W) с метапеременными, проверкой вхождения, обобщением до схематических типов, `InferError` |

## API

| Элемент | Назначение |
|------|---------|
| `Type::base` / `Type::nat` / `Type::boolean` | Базовые типы |
| `Type::arrow` | Функциональный тип `dom -> cod` |
| `Type::var` | Типовая переменная (схематическая `a` или метапеременная `?0`) |
| `Context::new` / `extend` / `lookup` | Контекст типизации; побеждает самая внутренняя привязка |
| `Term::var` / `abs` / `app` | Конструкторы бестиповых термов |
| `Term::beta_reduce` / `normalize` | Один β-шаг / нормальная форма (с ограничением топлива) |
| `Term::substitute` | Подстановка без захвата `M[x := N]` |
| `STerm::var` / `abs` / `app` | Конструкторы термов с аннотациями Чёрча |
| `STerm::check` / `type_of` | Проверка типа по контексту / по пустому контексту |
| `STerm::erase` | Стирание аннотаций до бестипового `Term` |
| `STerm::beta_reduce` / `normalize` | β-редукция с сохранением аннотаций (сохранение типа) |
| `infer` / `infer_in` | Вывод наиболее общего типа бестипового терма |
| `TypeError` / `InferError` | Почему терм не прошёл проверку типа |

## Основная идея

`λx. x` имеет тип `σ -> σ` для любого `σ`; проверенный на `Nat` он есть `Nat -> Nat`,
а его выведенный наиболее общий тип --- `a -> a`. Комбинатор K
`λx. λy. x` типизируется как `σ -> τ -> σ` (выведено `a -> b -> a`), что читается как
аксиома `A -> B -> A` минимальной логики. Самоприменение `λx. x x` не имеет
типа: ему понадобилось бы `σ = σ -> τ`, поэтому Ω = `(λx. x x)(λx. x x)` ---
незавершающийся терм бестиповой главы --- тоже отвергается. Сохранение
типа при редукции затем гарантирует, что тип типизированного терма является *инвариантом*
его вычисления: каждый β-шаг его сохраняет.

## Демо

| Демо | Что показывает |
|------|-------|
| `typed_terms` | Проверка тождества, K, числа Чёрча и композиции; некорректно типизированные термы (самоприменение, несоответствие, несвязанная переменная) отвергаются |
| `inference` | Вывод наиболее общего типа тождества, K, S, Чёрча 2; ω и Ω отвергаются проверкой вхождения |
| `subject_reduction` | `(λf:A→A. λx:A. f x)(λx:A. x)` редуцируется к `λx:A. x`, тип `A → A` сохраняется на каждом шаге |

## Тесты

```bash
cargo test -p type-theory
```

Набор покрывает тождество : σ→σ, K : σ→τ→σ, отвержение самоприменения
ω = λx. x x и сохранение типа при редукции на небольшом примере.
