# fol

Логика предикатов (логика первого порядка): термы, формулы, модели и истинность в стиле Тарского.

Язык логики первого порядка строится из сигнатуры констант, функциональных символов и предикатных символов.
Из сигнатуры мы строим термы (переменные, константы, применения функций) и формулы (атомы, равенство, связки и кванторы `∀` и `∃`).
Структура придаёт символам значение --- непустой домен, значение для каждой константы, тотальную функцию для каждого функционального символа, отношение для каждого предиката --- и истинность предложения вычисляется по определению Тарского.
На фиксированном конечном домене существует конечное число структур, поэтому выполнимость и общезначимость разрешимы перечислением.

## Быстрый старт

```bash
cargo run -p fol --example mortal
cargo run -p fol --example quantifier_scope
cargo run -p fol --example substitution
cargo run -p fol --example validity
cargo test -p fol
```

## Идея

Предикаты и кванторы позволяют формуле заглянуть внутрь атома.
`P(x)` --- это шаблон, который становится высказыванием, когда `x` связан квантором или заменён константой.
`∀x. P(x)` спрашивает о свойстве для каждого элемента домена, `∃x. P(x)` --- хотя бы для одного.
Порядок кванторов важен: `∀x ∃y L(x, y)` позволяет `y` зависеть от `x`, а `∃y ∀x L(x, y)` фиксирует один `y` для всех.

Структура превращает синтаксис в истинность: константы именуют элементы домена, функциональные символы именуют функции, предикатные символы именуют отношения.
Предложение тогда истинно или ложно согласно индуктивному определению Тарского, которое этот крейт реализует в `Structure::eval`.
На конечном домене кванторы сводятся к конечным конъюнкциям и дизъюнкциям, поэтому общезначимость и выполнимость можно решать перечислением всех структур --- именно это делают `valid_over` и `satisfiable_over`.

## API

| Элемент | Что делает |
|------|--------------|
| `Signature` | Константы, функции и предикаты языка с арностями |
| `Term` | Терм: `Var`, `Const`, `Fun` |
| `Formula` | Формула: `Pred`, `Eq`, `Not`, `And`, `Or`, `Implies`, `Forall`, `Exists` |
| `var` / `constant` / `func` | Конструкторы термов |
| `pred` / `eq` / `not` / `and` / `or` / `implies` / `forall` / `exists` | Конструкторы формул |
| `Term::substitute` | Замена переменной на терм |
| `Formula::substitute` | Подстановка без захвата; переименовывает связывающие переменные при необходимости |
| `Formula::free_vars` | Свободные переменные формулы |
| `Structure` | Модель: домен + интерпретация каждого символа |
| `Structure::eval` | Истинность предложения по Тарскому; `eval_with` добавляет присваивание переменных |
| `enumerate_structures` | Все структуры над фиксированным конечным доменом |
| `satisfiable_over` / `valid_over` | Выполнимость / общезначимость над фиксированным конечным доменом |
| `domain` | Канонический домен из `n` индивидов с именами `"0"` .. `"n-1"` |

## Демо

| Демо | Что показывает |
|------|---------------|
| `mortal` | «Каждый человек смертен» истинно в одном мире и ложно в другом |
| `quantifier_scope` | `∀x ∃y L(x, y)` против `∃y ∀x L(x, y)` --- порядок меняет истинность |
| `substitution` | Подстановка без захвата: связывающая переменная переименовывается, входящий терм остаётся свободным |
| `validity` | Закон исключённого третьего общезначим над конечными доменами; `∃x P(x)` выполнима, но не общезначима |
