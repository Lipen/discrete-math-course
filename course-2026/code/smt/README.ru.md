# smt

Небольшой стек DPLL(T) для бескванторных задач SMT, построенный послойно от булева ядра до драйвера смешанной сигнатуры.

Крейт --- это миниатюра истории SMT: SAT-решатель решает булеву структуру, решатели теорий решают конъюнкции арифметических или битовых литералов, а драйвер объединяет и то и другое, абстрагируя каждый атом теории до булевой переменной и изучая дизъюнкт при каждом конфликте теории.

## Быстрый старт

```bash
cargo run -p smt --example solve      # difference logic, satisfiable
cargo run -p smt --example unsat      # difference logic, negative cycle
cargo run -p smt --example mixed      # mixed formula through the DPLL(T) driver
cargo test -p smt
```

## Слои

| Модуль | Что делает |
|--------|--------------|
| `sat` | Автономный SAT-решатель DPLL: единичное распространение, решения, возврат (бэктрекинг). Движок для всех остальных модулей |
| `difference` | Разностная логика `x - y <= c`, решаемая как проверка на отрицательный цикл с помощью Беллмана–Форда |
| `linear` | Линейная арифметика над вещественными числами методом исключения Фурье–Моцкина с точной рациональной арифметикой (`Rat`) |
| `integers` | Линейная целочисленная арифметика методом ветвей и границ на рациональной релаксации |
| `bitvec` | Битовые векторы фиксированной ширины методом bit-blasting: каждое выражение превращается в схему из дизъюнктов, подаваемую на SAT-ядро |
| `driver` | Цикл DPLL(T): `smt::check(formula)` для смешанных формул с наивным изучением конфликтов |

Драйвер `driver` намеренно прост: одна теория на атом (без обмена переменными между теориями по Нельсону–Оппену), а линейные атомы-равенства отклоняются, потому что их отрицание --- это дизъюнкция; записывайте `sum == b` как два атома `sum <= b` и `-sum <= -b`.
Каждая теория документирует свои пределы точности: `linear` и `integers` сохраняют всю арифметику точной, но ожидают небольших коэффициентов (исключение их перемножает), а `bitvec` поддерживает ширины от 1 до 64 бит с операциями `Not`, `And`, `Or`, `Add`, `Sub`, `Extract`, `Eq`, `Neq` --- `Mul` и `Shl` завершаются явной ошибкой, а не неверным ответом.

## Демо

| Демо | Что показывает |
|------|---------------|
| `solve` | Небольшая выполнимая система разностной логики (`4 <= x0 - x1 <= 5` плюс `x2 - x1 <= 2`), найденное присваивание и повторная проверка каждого ограничения |
| `unsat` | Противоречивая пара (`x0 - x1 <= 2` и `x1 - x0 <= -3`), образующая отрицательный цикл; решатель возвращает `None` |
| `mixed` | Выполнимая смесь разностной логики, линейной арифметики и 4-битного `secret + 1 == 5`, а также невыполнимая дизъюнкция, обе ветви которой отвергаются разными теориями |

## Смешанная формула

```rust
use smt::difference::Constraint as Diff;
use smt::driver::{Atom, Formula, Verdict};

// (x0 - x1 <= 2) OR (x1 - x0 <= -3): a task that takes at most 2 time
// units or at least 3.
let f = Formula::Or(
    Box::new(Formula::Atom(Atom::Diff(Diff { x: 0, y: 1, c: 2 }))),
    Box::new(Formula::Atom(Atom::Diff(Diff { x: 1, y: 0, c: -3 }))),
);
assert_eq!(smt::check(&f).unwrap(), Verdict::Sat);
```

## API

| Элемент | Что делает |
|------|--------------|
| `sat::solve(num_vars, &clauses)` | Булева модель (одно значение на переменную) или `None` |
| `sat::Solver` | Инкрементальные дизъюнкты, `solve()` можно повторять после изучения |
| `difference::Constraint { x, y, c }` | Литерал `x - y <= c` |
| `difference::solve(&[Constraint])` | Присваивание или `None` (отрицательный цикл) |
| `linear::Constraint { coeffs, b, rel }` | `sum <rel> b` над вещественными числами (`Le`, `Lt`, `Eq`) |
| `linear::solve(&[Constraint])` | Точное рациональное присваивание или `None` |
| `linear::Rat` | Точное рациональное число `num / den` с `to_f64`, `floor`, `ceil` |
| `integers::Constraint { coeffs, b }` | `sum <= b` над целыми числами |
| `integers::solve(&[Constraint])` | Целочисленное присваивание или `None` |
| `bitvec::Expr` | Выражения битовых векторов: `Const`, `Var`, `Not`, `And`, `Or`, `Add`, `Sub`, `Extract` |
| `bitvec::BoolExpr` | Верхнеуровневые литералы `Eq` / `Neq` |
| `bitvec::solve(&[BoolExpr])` | `Ok(Some(model))` / `Ok(None)` / `Err(BitvecError)` |
| `driver::Atom` | Атом `Diff`, `Linear`, `Integer` или `Bitvec` |
| `driver::Formula` | `Atom`, `Not`, `And`, `Or` |
| `smt::check(&Formula)` | `Ok(Sat)` или `Ok(Unsat)`, либо ошибка для неподдерживаемых литералов |
