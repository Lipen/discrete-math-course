# codes

Помехоустойчивые коды над двоичным каналом: чётность, повторение и Хэмминг.

Три семейства кодов отвечают на один и тот же вопрос — «как защитить биты от шума?» — с разным объёмом избыточности:

| код                 | (n, k, d) | скорость k/n | обнаруживает | исправляет | идея                                                                                            |
| ---                 | ---       | ---          | ---          | ---        | ---                                                                                             |
| чётность            | (5, 4, 2) | 4/5          | 1            | 0          | добавить один бит, чтобы в слове было чётное число единиц                                       |
| повторение          | (3, 1, 3) | 1/3          | 2            | 1          | послать каждый бит трижды, голосование большинством                                             |
| Хэмминг             | (7, 4, 3) | 4/7          | 2            | 1          | биты чётности, чьи позиции указывают на ошибку                                                  |
| расширенный Хэмминг | (8, 4, 4) | 1/2          | 3            | 1          | Хэмминг(7,4) плюс общий бит чётности: двойная ошибка обнаруживается, а не исправляется ошибочно |

`(n, k, d)`: n бит на кодовое слово, k бит данных, минимальное расстояние d.
Код с расстоянием d обнаруживает до d - 1 ошибок и исправляет до (d - 1) / 2.
Все четыре обнаруживают одиночную ошибку.
Повторение, Хэмминг и расширенный Хэмминг также исправляют её, причём Хэмминг делает это почти при вдвое большей скорости.

## Быстрый старт

```bash
cargo test
cargo run --example hamming_demo
cargo run --example codes_compare
cargo run --example hamming_errors
cargo run --example hamming_extended
cargo run --example repetition_errors
cargo run --example parity_errors
```

| Пример              | Что он показывает                                                 |
| ---                 | ---                                                               |
| `hamming_demo`      | Одно слово через весь конвейер Хэмминга                           |
| `codes_compare`     | Три семейства рядом: скорость против расстояния                   |
| `hamming_errors`    | Хэмминг при 0, 1, 2, 3 перевёрнутых битах                         |
| `hamming_extended`  | Расширенный Хэмминг: как один бит чётности отличает 1 ошибку от 2 |
| `repetition_errors` | Повторение при 0, 1, 2, 3 перевёрнутых битах                      |
| `parity_errors`     | Чётность при 0, 1, 2, 3 перевёрнутых битах                        |

Демо `*_errors` рисуют перевёрнутые биты красным, когда терминал это поддерживает.

## Хэмминг(7,4)

Биты данных сидят на позициях 3, 5, 6, 7.
Биты чётности `p1`, `p2`, `p4` сидят на позициях 1, 2, 4.
Каждый бит чётности — это xor (сумма по модулю 2) покрываемых им битов данных:

![Хэмминг(7,4): какие биты данных питают каждый бит чётности](assets/hamming-7-4.svg)

$$ p_1 = d_1 \oplus d_2 \oplus d_4, \qquad
   p_2 = d_1 \oplus d_3 \oplus d_4, \qquad
   p_4 = d_2 \oplus d_3 \oplus d_4 $$

Эквивалентно, в терминах позиций внутри 7-битного слова:

| бит чётности | покрывает позиции |
| ---          | ---               |
| `p1`         | 1, 3, 5, 7        |
| `p2`         | 2, 3, 6, 7        |
| `p4`         | 4, 5, 6, 7        |

Декодер пересчитывает три чётности принятого слова.
Они образуют 3-битный синдром

$$ s = (s_4\, s_2\, s_1)_2 . $$

Прочитайте `s` как двоичное число: оно кодирует **номер бита, который нужно перевернуть обратно**, и эта интерпретация верна, **если произошло не более одной ошибки**.
При двух перевёрнутых битах `s` остаётся ненулевым, но указывает на неверную позицию, поэтому декодер «исправляет» бит, который никогда не был ошибочным.
При трёх перевёрнутых битах `s` может быть нулём, и ошибки проскальзывают незамеченными — цена кода с расстоянием 3.

## Расширенный Хэмминг (8, 4, 4)

Хэмминг(7,4) плюс один общий бит чётности: всё 8-битное слово должно иметь чётное число единиц.
Минимальное расстояние вырастает до 4, и декодер теперь отличает двойную ошибку от одиночной:

| синдром   | чётность | что делает декодер                                            |
| ---       | ---      | ---                                                           |
| 0         | чётная   | нет ошибки                                                    |
| 0         | нечётная | сам бит чётности был перевёрнут: исправить бит 8              |
| ненулевой | нечётная | одиночная ошибка: исправить бит, на который указывает синдром |
| ненулевой | чётная   | две ошибки: обнаружены, оставлены неисправленными             |

Без дополнительного бита двойная ошибка молча исправлялась ошибочно: синдром указывал на здоровый бит, и декодер переворачивал его.
Общий бит чётности устраняет эту неоднозначность — `extended_decode` сообщает `ExtendedOutcome::Double`, и данным не доверяют.

## Повторение (3, 1, 3)

Каждый бит посылается трижды, и приёмник принимает решение голосованием большинства.
Одиночная ошибка проигрывает голосование, две — выигрывают.
Этот код — честный наивный ответ на шум: он работает, но тратит три бита на защиту одного.

## Чётность (n + 1, n, 2)

Добавляется один бит чётности, чтобы в слове было чётное число единиц.
Одиночный перевёрнутый бит ломает проверку.
Проверка ничего не говорит о том, *где* находится ошибка, поэтому чётность обнаруживает, не исправляя.

## Расстояние и возможности

`hamming_distance`, `min_distance`, `detects_up_to` и `corrects_up_to` измеряют код и говорят, что он даёт:

```rust
let d = min_distance(&words);
assert_eq!(detects_up_to(d), 2);   // d - 1
assert_eq!(corrects_up_to(d), 1);  // (d - 1) / 2
```

## Модули

| Модуль       | Что внутри                                                   |
| ---          | ---                                                          |
| `hamming`    | `encode`, `syndrome`, `data_bits`, `decode`, `Decoded`       |
| `extended`   | `encode`, `decode`, `Outcome`, `Decoded`                     |
| `repetition` | `encode`, `decode`                                           |
| `parity`     | `bit`, `encode`, `ok`, `decode`                              |
| `distance`   | `hamming`, `min_distance`, `detects_up_to`, `corrects_up_to` |

Все публичные элементы также реэкспортируются из корня крейта под своими привычными именами (`codes::encode`, `codes::parity_bit`, `codes::extended_decode` и т. д.), так что существующий код продолжает работать.

## API

| Функция            | Модуль       | Назначение                                                             |
| ---                | ---          | ---                                                                    |
| `encode`           | `hamming`    | 4 бита данных -> 7-битное кодовое слово Хэмминга                       |
| `syndrome`         | `hamming`    | 0 для корректного кодового слова, иначе позиция одиночной ошибки       |
| `decode`           | `hamming`    | Исправляет одиночную ошибку и возвращает биты данных                   |
| `data_bits`        | `hamming`    | Извлекает 4 бита данных из 7-битного слова                             |
| `extended::encode` | `extended`   | 4 бита данных -> 8-битное расширенное кодовое слово Хэмминга           |
| `extended::decode` | `extended`   | Исправляет одну ошибку, обнаруживает две, возвращает `ExtendedDecoded` |
| `repeat_encode`    | `repetition` | Один бит -> тот же бит трижды                                          |
| `repeat_decode`    | `repetition` | Голосование большинством по трём битам                                 |
| `parity_bit`       | `parity`     | 1, когда в данных нечётное число единиц                                |
| `parity_encode`    | `parity`     | Добавляет бит чётности: код (n + 1, n, 2)                              |
| `parity_ok`        | `parity`     | True, когда слово проходит проверку на чётность                        |
| `parity_decode`    | `parity`     | Снимает бит чётности, если проверка проходит, иначе `None`             |
| `hamming_distance` | `distance`   | Число различающихся позиций между двумя битовыми строками              |
| `min_distance`     | `distance`   | Наименьшее попарное расстояние по множеству кодовых слов               |
| `detects_up_to`    | `distance`   | d - 1: ошибки, обнаруживаемые кодом с расстоянием d                    |
| `corrects_up_to`   | `distance`   | (d - 1) / 2: ошибки, исправляемые кодом с расстоянием d                |

`hamming::Decoded` сообщает восстановленные данные, сколько ошибок было исправлено (0 или 1) и где.
`extended::Decoded` сообщает данные и `Outcome`: `Clean`, `Corrected` или `Double`.

```bash
cargo test
```

Покрытие:

- Хэмминг(7,4): проверены все 16 кодовых слов, исправлены все 16 x 7 однобитовых искажений, проверены все 16 x 15/2 = 120 пар слов на d >= 3, проверено ошибочное исправление двойной ошибки, проверена таблица синдромов, сверено с независимо вычисленным словом.
- Расширенный Хэмминг(8,4,4): все 16 кодовых слов имеют чётное число единиц, исправлены все 16 x 8 однобитовых искажений, обнаружены все 16 x 28 двухбитовых искажений, проверены сценарии «только бит чётности» и «данные+бит чётности», подтверждено d = 4.
