# code — исполняемый компаньон книги «Дискретная математика»

Каждому большому разделу книги соответствует отдельный Rust-крейт.
Разобранные в книге примеры реализованы как запускаемые `examples/`,
базовые алгоритмы — в библиотеке крейта и покрыты тестами.

## Структура

| Крейт | Глава | Содержание |
|-------|-------|------------|
| `automata` | m17 | ДКА и НКА (с ε), детерминизация, операции над языками, регулярки, минимизация |
| `lambda` | m21 | Термы, подстановка без захвата, β-редукция, числа Чёрча |
| `crypto` | m13 | Евклид, модулярная арифметика, RSA, атаки |
| `turing` | m19 | Лента на двух стеках, машина Тьюринга, `0^n1^n` |

Крейты независимы: общих абстракций почти нет. Дублирование с адаптацией
под задачу выигрывает у раннего выноса в общий модуль.

## Как собрать и запустить

```bash
cargo build --workspace     # собрать всё
cargo test --workspace      # прогнать все тесты
cargo run -p crypto --example common_modulus   # конкретный пример
```

Список примеров крейта: `cargo run -p <креп> --example` с именем файла,
либо `ls <креп>/examples`.

## Атаки (m13)

Раздел «Взлом» главы о криптографии реализован в крейте `crypto`:

| Пример | Атака |
|--------|-------|
| `brute_force_caesar` | полный перебор сдвигов шифра Цезаря |
| `frequency_analysis` | частотный анализ шифра простой замены |
| `common_modulus` | атака с общим модулем на RSA |
| `malleability` | маллобильность RSA (подделка шифротекста) |
| `pohlig_hellman` | атака Полига—Хеллмана на DLOG в группе с гладким порядком |

Функции атак лежат в `crypto::attacks` и покрыты тестами.

## Автоматы (m17)

Глава о конечных автоматах реализована в крейте `automata`:

| Возможность | Что это |
|-------------|---------|
| `Dfa` | приём слов; дополнение; произведение (объединение, пересечение, разность); минимизация Мура |
| `Nfa` | ε-переходы, ε-замыкание, приём слов; `to_dfa` --- конструкция подмножеств |
| `RegEx` | парсер строки и конструкция Томпсона `to_nfa` |

| Пример | Что показывает |
|--------|----------------|
| `even_ones` | простейший ДКА: чётное число единиц |
| `nfa_to_dfa` | детерминизация НКА «содержит 00 или 11» |
| `regex_matching` | `(a|b)*a(a|b)` через Томпсон и подмножества |
| `language_ops` | объединение/пересечение/дополнение через произведение |
| `minimize` | сжатие ДКА с неразличимыми состояниями |

## Заметки

- `crypto` работает на `u64` — учебные числа; полноценные RSA-ключи требуют
  произвольной точности (`num-bigint`), добавим при необходимости.
- `automata` и `turing` описывают собственные модели слов и ленты —
  у каждой задачи свои требования.
