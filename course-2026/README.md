# Course 2026/27: новый курс дискретной математики (WIP)

Эта папка содержит **реальную разработку** нового курса дискретной математики для 2026/27.
Внутренний рабочий документ, **не для публикации**: описание курса, материалы, идеи для вдохновения.
Не финальный продукт, а живой черновик.

## Как устроено три слоя

| Слой | Где | Назначение |
|---|---|---|
| **Текущий опубликованный курс** | `typst/` (корень репо) | Действующий 1-семестровый курс на GitHub Pages. Не трогаем. |
| **Управление процессом** | `.dev/1_active/discrete-math-2026/` | Планы, спеки, дорожная карта, диаграммы. То, **КАК** мы строим курс. |
| **Сам курс в разработке** | `course-2026/` (эта папка) | Документы и материалы. То, **ЧЕМ** курс является. Со временем здесь появляются лекции/ДЗ/КР; созревшее переносим в опубликованный `typst/`. |

## Что внутри сейчас

- `course-description.md` — описание курса (читаемый проспект: зачем, как, философия).
- `ideas.md` — общие идеи, вдохновение, педагогические эксперименты.

Ранний набросок: описание + идеи.
Наполнение модулей и реальные материалы появляются по мере разработки, согласно планам в `.dev/1_active/discrete-math-2026/` (в первую очередь `modules.md`, `assessments.md`, `migration.md`).
