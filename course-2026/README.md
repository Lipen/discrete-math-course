# Дискретная математика — курс и книга, 2026/27

В этом репозитории — разработка курса «Дискретная математика» для программистов первого курса и одноимённой книги.
Один и тот же материал живёт в трёх независимых медиумах: книга, лекции, код.

## Что внутри

| Папка | Что это | Сборка |
|---|---|---|
| `notes/` | Книга на Typst, 28 глав | `typst compile notes/book.typ` |
| `lectures/` | Слайды лекций на Typst | `typst compile lectures/lec-*.typ` |
| `code/` | Rust-крейты по темам книги | `cargo test --workspace` |
| `course/` | Документы курса: проспект, планы, расписание, опросники | `typst compile --root . course/*.typ` |

## Документы курса

Документы курса лежат в `course/`:

- `course/course-description.md` — что это за курс, зачем, как устроен.
- `course/topics-s1.typ` — разбивка тем семестра 1.
- `course/topics-s2.typ` — разбивка тем семестра 2.
- `course/schedule-s1.typ` — понедельное расписание семестра 1 (лекции, контрольные, мидтермы, экзамен).
- `course/flash-quizzes-s1.typ` — флеш-опросники к лекциям семестра 1 (пул вопросов и микро-задач).

## Три медиума независимы

Книга — справочник, лекции — устный материал, код — модели.
Они не ссылаются друг на друга, но согласованы по терминам и обозначениям.
Книга шире курса: в ней есть главы, не входящие в лекции.

## Сборка

```bash
typst compile notes/book.typ /tmp/book.pdf
cargo test --workspace
cargo clippy --workspace --all-targets
```
