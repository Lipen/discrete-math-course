# Дискретная математика

Материалы двухсеместрового курса "Дискретная математика" для программистов.

## 📚 Что в репозитории

| Раздел | Содержание |
|---|---|
| 📖 `book/` | Книга-справочник по курсу (Typst) |
| 🎞️ `lectures/` | Слайдовые лекции |
| 🦀 `code/` | Программные модели (Rust) |
| 📋 `course/` | Рабочая программа, темы, расписания |
| 🧾 `homework/` | Комплекты домашних заданий |

## ⚙️ Сборка

```bash
just               # показать все команды
just book          # собрать книгу
just lectures      # собрать лекции
just course/all    # собрать документы курса
just homework      # собрать домашние задания
just test          # запустить тесты
```
