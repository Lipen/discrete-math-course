# Дискретная математика

Материалы двухсеместрового курса «Дискретная математика» для программистов и научно-популярная книга по курсу.

Собранные PDF публикуются на GitHub Pages: **https://Lipen.github.io/discrete-math-course/** — книга, лекции, домашние задания, документы курса.

## Что в репозитории

| Раздел | Содержание |
|---|---|
| `book/` | Книга-справочник (Typst): 35 глав, `book.typ` — корень сборки, `diagrams/` — CeTZ-диаграммы |
| `lectures/` | Слайдовые лекции: два семестра (`s1-lec*.typ`, `s2-lec*.typ`) |
| `homework/` | Комплекты домашних заданий (`hw1.typ` … `hw8.typ`) |
| `course/` | Документы курса: силлабус, РПД, планы семестров, хендбук ментора |
| `code/` | Rust code-компаньон: крейты по темам книги |
| `tools/` | Скрипты проверок (целостность меток упражнений) |
| `typst/`, `tex/`, `docs/` и др. | Архив 2023–2025: заморожено, только читаем |

## Сборка

Нужны: [just](https://github.com/casey/just), [typst](https://github.com/typst/typst) 0.15, Rust (для тестов), pandoc + xelatex (для РПД).

```bash
just               # показать все команды
just all           # собрать книгу, лекции, документы курса, домашки
just book          # собрать книгу
just lectures      # собрать лекции
just course/all    # собрать документы курса
just homework      # собрать домашние задания
just test          # тесты code-компаньона
```

Шрифты: Libertinus, Source Sans, Font Awesome.

## Качество

Пре-коммит хуки на [prek](https://github.com/j178/prek): форматирование Typst (typstyle), cargo fmt, проверки согласованности меток упражнений и базовая санитария. CI собирает всё и выкладывает на Pages.
